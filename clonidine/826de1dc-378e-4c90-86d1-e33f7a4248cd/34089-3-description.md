# 11 DESCRIPTION

QLONILIK contains clonidine, a central alpha-2 adrenergic agonist, available as a solution for oral administration.
Clonidine hydrochloride is an imidazoline derivative and exists as a mesomeric compound.
The chemical name is 2-(2,6-dichlorophenylamino)-2-imidazoline hydrochloride.
The molecular formula for clonidine hydrochloride is C9H9Cl2N3 ·HCl and the molecular weight is 266.55 g/mol.

Clonidine hydrochloride USP is an odorless, bitter, white, crystalline substance soluble in water and alcohol.

QLONILIKTM (clonidine hydrochloride) Oral Solution is a clear, colorless solution for oral administration.
Each mL contains 0.05 mg clonidine hydrochloride (equivalent to 0.043 mg clonidine) and the following inactive ingredients: methylparaben, propylene glycol, propylparaben, purified water, raspberry flavor, sodium phosphate dibasic dihydrate, sodium phosphate monobasic dihydrate, and sucralose.
