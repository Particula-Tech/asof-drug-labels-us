# HOW SUPPLIED

Clonidine Transdermal System, USP is available as 0.1 mg/day, 0.2 mg/day and 0.3 mg/day of clonidine, USP and are supplied as 4 pouched systems and 4 adhesive covers per carton.
Each system is a rectangular patch with rounded corners consisting of a peach-colored backing, an adhesive layer, and an oversized removable release liner.
Each patch is overlaid and underlaid with additional release liners.
