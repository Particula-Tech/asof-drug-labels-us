# HOW SUPPLIED

Doxazosin mesylate tablet is available as colored tablets for oral administration.
Each scored tablet contains doxazosin mesylate equivalent to 1 mg (white), 2 mg (yellow), 4 mg (orange) or 8 mg (green) of the active constituent, doxazosin.

|  | 4 mg (NDC 59762-2340-6) |
|  | 8 mg (NDC 59762-2380-6) |

## Recommended Storage

Store at 25°C (77°F); excursions permitted to 15–30°C (59–86°F) [see USP Controlled Room Temperature].
