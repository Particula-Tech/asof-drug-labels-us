# 11 DESCRIPTION

ETOPOPHOS (etoposide phosphate) is a topoisomerase inhibitor.
The chemical name for etoposide phosphate is: 4'-Demethylepipodophyllotoxin 9-[4,6-O-(R)-ethylidene-β-D-glucopyranoside], 4' (dihydrogen phosphate).

Etoposide phosphate has the following structure:

Etoposide phosphate is a phosphate ester of etoposide, a semi-synthetic derivative of podophyllotoxin.
ETOPOPHOS is available for intravenous infusion as a sterile lyophilized powder in single-dose vials for reconstitution containing 114 mg etoposide phosphate, equivalent to 100 mg etoposide, 32.7 mg sodium citrate USP, and 300 mg dextran 40.
