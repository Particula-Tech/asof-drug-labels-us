# 3 DOSAGE FORMS AND STRENGTHS

Subcutaneous Injection: colorless to yellow, and clear to slightly opalescent solution.

SKYRIZI Pen

- Injection: 150 mg/mL in a single-dose prefilled pen.

SKYRIZI Prefilled Syringe

- Injection: 55 mg/0.37 mL in a single-dose prefilled syringe.
- Injection: 150 mg/mL in a single-dose prefilled syringe.
- Injection: 180 mg/1.2 mL (150 mg/mL) in a single-dose prefilled syringe.

SKYRIZI Prefilled Cartridge with Supplied On-Body Injector

- Injection: 180 mg/1.2 mL (150 mg/mL) in a single-dose prefilled cartridge for use with the on-body injector.
- Injection: 360 mg/2.4 mL (150 mg/mL) in a single-dose prefilled cartridge for use with the on-body injector.

Intravenous Infusion: colorless to slightly yellow, and clear to slightly opalescent solution.

SKYRIZI Vial

- Injection: 600 mg/10 mL (60 mg/mL) in a single-dose vial.
