# 11 DESCRIPTION

Chemically, codeine is Morphinan-6-ol,7,8-didehydro-4,5-epoxy-3-methoxy-17-methyl-(5α,6α)-, sulfate (2:1) (salt), trihydrate.
Its empirical formula is C18H21NO3 and its molecular weight is 299.36.

Each tablet contains 15, 30, or 60 mg of codeine sulfate and the following inactive ingredients: microcrystalline cellulose, colloidal silicon dioxide, magnesium stearate, talc and stearic acid.
