# 16 HOW SUPPLIED/STORAGE AND HANDLING

## 16.1 How Supplied

Ontralfy contains 2 mg/5 mL tizanidine.
It is a clear, colorless to pale yellow solution with strawberry flavor and is supplied in bottles of 473 mL with child-resistant closure (NDC 69528-310-16).

## 16.2 Storage and Handling

Store at 20°C to 25°C (68°F to 77°F); excursions permitted between 15°C to 30°C (59°F to 86°F) [see USP Controlled Room Temperature].

Dispense in containers with child-resistant closure.
