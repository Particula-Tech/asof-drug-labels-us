# 11 DESCRIPTION

The chemical name of lacosamide, the single (R)-enantiomer, is (R)-2-acetamido-N-benzyl-3-methoxypropionamide (IUPAC).
Lacosamide is a functionalized amino acid.
Its molecular formula is C 13H 18N 2O 3and its molecular weight is 250.30.
The chemical structure is:

Lacosamide, USP is a white to light yellow powder.
It is sparingly soluble in water and slightly soluble in acetonitrile, soluble in dichloromethane and methanol.
