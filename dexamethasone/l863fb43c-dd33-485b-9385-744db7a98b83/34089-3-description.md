# DESCRIPTION

MAXIDEX®(Dexamethasone Sodium Phosphate) is an adrenocortical steroid prepared as a sterile ophthalmic ointment.
The active ingredient is represented by the chemical structure:

Established name:

Dexamethasone Sodium Phosphate

Chemical name:

Pregn-4-ene-3,20-dione,9-fluoro-11,17-dihydroxy-16-methyl-21-(phosphonoxy)-, disodium salt, (11β,16α)-.

Each gram contains: Active: Dexamethasone Sodium Phosphate equivalent to Dexamethasone Phosphate 0.5 mg (0.05%) Inactive: Mineral Oil.

White Petrolatum.
