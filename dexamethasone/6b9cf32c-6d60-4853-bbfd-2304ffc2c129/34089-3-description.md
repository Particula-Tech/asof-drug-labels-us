# 11 DESCRIPTION

HEMADY (dexamethasone, USP) is an anti-inflammatory, 9-fluoro-glucocorticoid.
The chemical name is 9-fluoro-11β,17,21trihydroxy-16α-methylpregna-1,4-diene-3,20-dione.
The molecular weight is 392.47 g/mol.
The molecular formula is C22H29FO5.
The structural formula is:

Dexamethasone is a white to practically white, odorless, crystalline powder.
It is stable in air.
It is practically insoluble in water.

HEMADY for oral administration is available as an immediate-release tablet in a strength of 20 mg.
Each tablet contains dexamethasone USP and the following inactive ingredients: corn starch NF, lactose monohydrate NF, magnesium stearate NF, povidone NF, and sodium starch glycolate NF.
