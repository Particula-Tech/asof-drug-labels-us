# DESCRIPTION

MAXIDEX® 0.1% (dexamethasone ophthalmic suspension) is an adrenocortical steroid prepared as a sterile topical ophthalmic suspension.
The active ingredient is represented by the chemical structure:

Each mL contains: Active: dexamethasone 0.1%.
Preservative: benzalkonium chloride 0.01%.
Vehicle: hypromellose 0.5%.
Inactives: sodium chloride, dibasic sodium phosphate, polysorbate 80, edetate disodium, citric acid and/or sodium hydroxide (to adjust pH), purified water.
