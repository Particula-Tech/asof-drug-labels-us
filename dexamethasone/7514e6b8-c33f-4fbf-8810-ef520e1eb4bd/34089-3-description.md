# 11 DESCRIPTION

DEXTENZA (dexamethasone ophthalmic insert) is a fluorescent yellow, 3 mm cylindrical-shaped, resorbable, sterile insert for intracanalicular use.
DEXTENZA contains 0.4 mg dexamethasone in a polyethylene glycol (PEG) based hydrogel conjugated with fluorescein.
DEXTENZA does not contain an antimicrobial preservative.
The active ingredient is represented by the chemical structure:

The chemical name for dexamethasone is 9-Fluoro-11β,17,21-trihydroxy-16α-methylpregna-1,4-diene-3,20-dione.
It has a molecular formula of C22H29FO5 and a molecular weight of 392.47 g/mol.
Dexamethasone is a crystalline powder.

Each DEXTENZA contains: Active ingredients: 0.4 mg dexamethasone.
Inactive ingredients: 4-arm polyethylene glycol (PEG) N-hydroxysuccinimidyl glutarate (20K), trilysine acetate, N-hydroxysuccinimide-fluorescein, sodium phosphate dibasic, sodium phosphate monobasic, water for injection.
