# DESCRIPTION

Pyridostigmine bromide tablets, USP (pyridostigmine bromide) are an orally active cholinesterase inhibitor.
Chemically, pyridostigmine bromide is 3-hydroxy-1-methylpyridinium bromide dimethylcarbamate.
