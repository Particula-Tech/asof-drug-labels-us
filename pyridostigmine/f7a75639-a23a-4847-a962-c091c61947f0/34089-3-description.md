# DESCRIPTION

Pyridostigmine bromide is an orally active cholinesterase inhibitor.
Chemically, Pyridostigmine bromide is 3-hydroxy-1-methylpyridinium bromide dimethylcarbamate.

Pyridostigmine bromide is available in the following form: Extended-release tablets containing 180 mg Pyridostigmine bromide, each tablet also contains colloidal silicon dioxide, carnauba wax, tribasic calcium phosphate, zein (corn protein) and magnesium stearate.

ACTIONS

Pyridostigmine bromide inhibits the destruction of acetylcholine by cholinesterase and thereby permits freer transmission of nerve impulses across the neuromuscular junction.
Pyridostigmine is an analog of neostigmine (Prostigmin®), but differs from it in certain clinically significant respects, for example, Pyridostigmine is characterized by a longer duration of action and fewer gastrointestinal side effects.
INDICATION

Pyridostigmine bromide is useful in the treatment of myasthenia gravis.
