# 11 DESCRIPTION

Pemetrexed is a folate analog metabolic inhibitor.
The drug substance, pemetrexed disodium (2.5 H2O), has the chemical name N-[[4-[2-(2-Amino-4-oxo-4,7-dihydro-1H-pyrrolo[2,3-d]pyrimidin-5-yl)ethyl]phenyl]carbonyl]-L-glutamic acid disodium, hemipentahydrate with a molecular formula of C20H19N5Na2O6 ∙2.5H2O and a molecular weight of 516.41.
