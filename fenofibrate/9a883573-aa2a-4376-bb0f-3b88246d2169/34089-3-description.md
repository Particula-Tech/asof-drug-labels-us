# DESCRIPTION

LIPOFEN® (fenofibrate capsules, USP), is a lipid regulating agent available as hard gelatin capsules for oral administration.
Each hard gelatin capsule contains 50 or 150 mg of fenofibrate, USP.
The chemical name for fenofibrate is 2-[4-(4-chlorobenzoyl) phenoxy]-2-methyl-propanoic acid, 1-methylethyl ester with the following structural formula:

The empirical formula is C20H21O4C1 and the molecular weight is 360.83; fenofibrate is insoluble in water.
The melting point is 79-82°C.
Fenofibrate is a white solid which is stable under ordinary conditions.

LIPOFEN® (fenofibrate capsules, USP) meets USP Dissolution Test 2.

Inactive Ingredients: Each hard gelatin capsule contains Gelucire 44/14 (lauroyl macrogol glyceride type 1500), polyethylene glycol 20,000, polyethylene glycol 8000, hydroxypropylcellulose, sodium starch glycolate, gelatin, titanium dioxide, shellac, propylene glycol, may also contain black iron oxide, FD&C Blue #1, FD&C Blue #2, FD&C Red #40, D&C Yellow #10.
