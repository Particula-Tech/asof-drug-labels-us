# DESCRIPTION

Propranolol hydrochloride is a synthetic beta-adrenergic receptor blocking agent chemically described as (+)-1-(isopropylamino)-3-(1-naphthyloxy)-2-propanol hydrochloride.
Its structural formula is:

C16H21NO2•HCl

Propranolol hydrochloride is a stable, white, crystalline solid which is readily soluble in water and ethanol.
Its molecular weight is 295.80.

Propranolol hydrochloride injection is available as a sterile injectable solution for intravenous administration.
Each mL contains 1 mg of propranolol hydrochloride in Water for Injection.
The pH is adjusted with citric acid.
