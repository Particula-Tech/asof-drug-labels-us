# DESCRIPTION

Benzonatate capsules, USP, a non-narcotic oral antitussive agent, is 2,5,8,11,14,17,20,23,26-nonaoxaoctacosan-28-yl p-(butylamino) benzoate; with molecular weight of 603.7.

Each benzonatate capsule for oral administration contains 100 mg or 200 mg of benzonatate.
In addition, each capsule also contains the following inactive ingredients: gelatin, glycerin, noncrystallising sorbitol solution, methylparaben, propylparaben and purified water.
