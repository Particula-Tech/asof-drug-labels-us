# DESCRIPTION

CARAFATE Oral Suspension contains sucralfate and sucralfate is an α-D-glucopyranoside, β-D- fructofuranosyl-, octakis-(hydrogen sulfate), aluminum complex.

CARAFATE Oral Suspension for oral administration contains 1 g of sucralfate per 10 mL.
CARAFATE Oral Suspension also contains: colloidal silicon dioxide NF, FD&C Red #40, flavor, glycerin USP, methylcellulose USP, methylparaben NF, microcrystalline cellulose NF, purified water USP, simethicone USP, and sorbitol solution USP.
Therapeutic category: antiulcer.
