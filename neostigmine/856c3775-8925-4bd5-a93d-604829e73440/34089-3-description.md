# 11 DESCRIPTION

Neostigmine methylsulfate, a cholinesterase inhibitor, is (m-hydroxyphenyl) trimethylammonium methylsulfate dimethylcarbamate.
The structural formula is:

Neostigmine methylsulfate, USP is a white crystalline powder and is very soluble in water and soluble in alcohol.
Neostigmine methylsulfate injection, USP is a clear, colorless, sterile, nonpyrogenic solution intended for intravenous use.

Each mL of the 0.5 mg/mL strength contains neostigmine methylsulfate USP, 0.5 mg, phenol 4.5 mg (used as preservative) and sodium acetate trihydrate 0.2 mg, in water for injection.
The pH is adjusted, when necessary, with acetic acid/sodium hydroxide to achieve a value of 5.5.

Each mL of the 1 mg/mL strength contains neostigmine methylsulfate USP, 1 mg, phenol 4.5 mg (used as preservative), and sodium acetate trihydrate 0.2 mg, in water for injection.
The pH is adjusted, when necessary, with acetic acid/sodium hydroxide to achieve a value of 5.5.
