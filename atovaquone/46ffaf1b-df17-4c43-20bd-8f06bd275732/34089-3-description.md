# DESCRIPTION

MEPRON (atovaquone) is an antiprotozoal agent.
The chemical name of atovaquone is trans-2-[4-(4-chlorophenyl)cyclohexyl]-3-hydroxy-1,4-naphthalenedione.
Atovaquone is a yellow crystalline solid that is practically insoluble in water.
It has a molecular weight of 366.84 and the molecular formula C22H19ClO3.

MEPRON tablets are for oral administration.
Each film-coated tablet contains 250 mg of atovaquone and the inactive ingredients hydroxypropyl cellulose, hydroxypropyl methyl-cellulose, magnesium stearate, microcrystalline cellulose, polyethylene glycol, povidone, sodium starch glycolate, titanium dioxide, and yellow iron oxide.
