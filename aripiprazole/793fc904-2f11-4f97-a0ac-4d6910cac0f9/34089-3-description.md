# 11 DESCRIPTION

Aripiprazole is a psychotropic drug that is available as Aripiprazole Tablets.
Aripiprazole is 7-[4-[4-(2,3-dichlorophenyl)-1piperazinyl]butoxy]-3,4-dihydrocarbostyril.
The empirical formula is C23H27Cl2N3O2 and its molecular weight is 448.38.
