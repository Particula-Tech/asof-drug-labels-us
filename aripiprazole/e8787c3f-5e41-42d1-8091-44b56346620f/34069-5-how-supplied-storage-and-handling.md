# 16 HOW SUPPLIED/STORAGE AND HANDLING

## 16.1 How Supplied

The ABILIFY MYCITE kit contains aripiprazole tablets embedded with an Ingestible Event Marker (IEM) sensor co-packaged with MYCITE Patches (wearable sensors) (referred to as the patch).
The patch is available as either a:

- 1-component patch (see Table 17 and Figure 9).
  The 1-component kit contains (a) aripiprazole tablets with sensor and (b) patches (patches in this kit contain electronic components to record drug ingestion information and transfer the data to a compatible smartphone).
- 2-component patch comprised of a removable electronics module (referred to as the "pod") and an adhesive "strip" (see Table 18 and Figure 10).
  The pod contains electronic components to record drug ingestion information and transfer the data to a compatible smartphone.
  The 30 Day Starter kits contain (a) aripiprazole tablets with sensor, (b) strips, and (c) one pod; whereas, the Maintenance kits contain (a) aripiprazole tablets with sensor and (b) strips [see Dosage and Administration (2.2)].

Each patch has a corresponding IFU within the app.
The status of the patch is indicated by a status icon in the app to inform the user that the patch is properly adhered and fully functioning.

## 16.2 Storage

Tablet bottle:

Store 20°C to 25°C (68°F to 77°F); excursions permitted between 15°C to 30°C (59°F to 86°F) [see USP Controlled Room Temperature].

Do not store in conditions where tablets are exposed to humid conditions.

MYCITE Patch (Wearable Sensor):

Store between 5°C and 27°C (41°F to 81°F), 15% to 93% relative humidity.
