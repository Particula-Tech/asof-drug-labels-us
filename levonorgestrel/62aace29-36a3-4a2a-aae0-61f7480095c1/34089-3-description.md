# DESCRIPTION

Emergency contraceptive tablet.
Each Plan B® tablet contains 0.75 mg of a single active steroid ingredient, levonorgestrel [18,19-Dinorpregn-4-en-20-yn-3-one-13-ethyl-17-hydroxy-, (17α)- (-)-], a totally synthetic progestogen.
The inactive ingredients present are colloidal silicon dioxide, potato starch, gelatin, magnesium stearate, talc, corn starch, and lactose monohydrate.
