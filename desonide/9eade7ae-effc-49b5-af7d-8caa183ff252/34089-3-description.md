# DESCRIPTION

Desonide ointment, 0.05% contains desonide (Pregna-1,4-diene-3,20-dione,11,21 dihydroxy-16,17-[(1-methylethylidene)bis(oxy)]-,(11β,16α)) a synthetic corticosteroid for topical dermatologic use.
The corticosteroids constitute a class of primary synthetic steroids used topically as anti-inflammatory and antipruritic agents.

Chemically, desonide, the active ingredient in desonide ointment, 0.05% is C 24H 32O 6.

The molecular weight of desonide is 416.51.
It is white to off-white powder.
The solubility of desonide in distilled water saturated with the ether is 184 mg/L.

Each gram of desonide ointment, 0.05% contains 0.5 mg of desonide microdispersed in a base of white petrolatum.
