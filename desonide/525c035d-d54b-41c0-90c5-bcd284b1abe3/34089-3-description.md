# Description

Desonide Ointment contains desonide (Pregna-1,4-diene-3,20-dione,11,21-dihydroxy-16, 17-[(1-methylethylidene)bis(oxy)]-, (11β,16 α)) a synthetic corticosteroid for topical dermatologic use.
The corticosteroids constitute a class of primary synthetic steroids used topically as anti-inflammatory and antipruritic agents.

Chemically, desonide, the active ingredient in Desonide Ointment, is C24H32O6.

Desonide has the molecular weight of 416.51.
It is a white to off-white powder.
The solubility of desonide in distilled water saturated with ether is 184 mg/L.

Each gram of Desonide Ointment contains 0.5 milligrams of desonide microdispersed in a base of white petrolatum.
