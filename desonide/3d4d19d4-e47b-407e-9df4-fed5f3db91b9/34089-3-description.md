# DESCRIPTION

Desonide Ointment, 0.05% contains desonide (Pregna-1,4-diene-3,20-dione,11,21-dihydroxy-16,17-[(1-methylethylidene)bis(oxy)]-,(11ß,16α)) a synthetic corticosteroid for topical dermatologic use.
The corticosteroids constitute a class of primary synthetic steroids used topically as anti-inflammatory and antipruritic agents.
Chemically, desonide, the active ingredient in Desonide Ointment, 0.05% is C24H32O6.

The molecular weight of desonide is 416.51.
It is white to off-white powder.
The solubility of desonide in distilled water saturated with the ether is 184 mg/L.
Each gram of Desonide Ointment, 0.05% contains 0.5 milligram of desonide microdispersed in a base of white petrolatum.
