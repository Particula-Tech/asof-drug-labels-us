# Information for Patients

Patients using topical corticosteroids should receive the following information and instructions: 1.
This medication is to be used as directed by the physician.
It is for external use only.
Avoid contact with the eyes.
2.
This medication should not be used for any disorder than that for which it was prescribed.
3.
The treated skin area should not be bandaged, otherwise covered or wrapped, so as to be occlusive unless directed by the physician.
4.
Patients should report to their physician any signs of local adverse reactions.
