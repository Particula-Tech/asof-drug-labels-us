# HOW SUPPLIED

The final blended product is 500 mg of formulation containing 50 mg of doxycycline hyclate (doxycycline hyclate, 10%).

ATRIDOX® is available in a tray containing a doxycycline hyclate syringe (50 mg), an ATRIGEL® Delivery System syringe (450 mg), and a blunt cannula.
The trayed product is available in a professional sample box of two (NDC 59883-100-02) or a box of six (NDC 59883-100-06).

Each ATRIDOX® syringe system is intended for use in only one patient.
Do not use if packaging has been previously opened or damaged.

## Storage and Handling

Store at 2° - 30°C (36° - 86°F).
Rx Only
