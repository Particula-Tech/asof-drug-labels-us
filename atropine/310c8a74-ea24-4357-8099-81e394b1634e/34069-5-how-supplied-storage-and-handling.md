# 16 HOW SUPPLIED/STORAGE AND HANDLING

Atropine Sulfate Injection, USP is a non-pyrogenic, isotonic, clear solution and is supplied as follows:

| Presentation | Single Vial | 10 Vial Pack |  |
| --- | --- | --- | --- |
| NDC# | 63323-580-03 | 63323-580-20 |  |
| Description | 8 mg per 20 mL (0.4 mg per mL) Multiple-dose vial | 20 mL multiple-dose vial, packaged in a carton containing 10 vials. |  |

Store at 20° to 25°C (68° to 77°F) [see USP Controlled Room Temperature].
After initial use, store between 20° to 25°C (68° to 77°F) and discard within 24 hours.
