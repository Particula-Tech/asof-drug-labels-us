# DESCRIPTION

DEPO-Estradiol Injection contains estradiol cypionate for intramuscular use.
Each mL contains:

5 mg/mL—5 mg estradiol cypionate, 5.4 mg chlorobutanol anhydrous (chloral derivative) added as preservative; in 913 mg cottonseed oil.

Warning: Chlorobutanol may be habit forming.
The structural formula is represented below:

DEPO-Estradiol contains an oil soluble ester of estradiol 17β.
The chemical name for estradiol cypionate is estradiol 17-cyclopentanepropionate.
