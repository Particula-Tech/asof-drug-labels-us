# 11 DESCRIPTION

Pembrolizumab is a humanized monoclonal antibody that blocks the interaction between PD-1 and its ligands, PD-L1 and PD-L2.
Pembrolizumab is an IgG4 kappa immunoglobulin with an approximate molecular weight of 149 kDa.

KEYTRUDA is a sterile, preservative-free, white to off-white lyophilized powder in single-use vials.
Each vial is reconstituted and diluted for intravenous infusion.
Each 2 mL of reconstituted solution contains 50 mg of pembrolizumab and is formulated in L-histidine (3.1 mg), polysorbate-80 (0.4 mg), sucrose (140 mg).
May contain hydrochloric acid/sodium hydroxide to adjust pH to 5.5.
