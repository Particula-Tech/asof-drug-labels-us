# DESCRIPTION

Tretinoin Cream 0.025% is used for the topical treatment of acne vulgaris.
Tretinoin Cream contains tretinoin 0.025% by weight, in a hydrophilic cream vehicle of stearic acid, polyolprepolymer-2, isopropyl myristate, polyoxyl 40 stearate, propylene glycol, stearyl alcohol, xanthan gum, sorbic acid, butylated hydroxytoluene and purified water.
