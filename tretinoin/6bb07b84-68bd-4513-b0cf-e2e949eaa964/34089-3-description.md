# DESCRIPTION

AVITA® Gel, a topical retinoid, contains tretinoin 0.025% by weight in a gel vehicle of butylated hydroxytoluene, hydroxypropyl cellulose, polyolprepolymer-2, and ethanol (denatured with tert-butyl alcohol and brucine sulfate) 83% w/w.
