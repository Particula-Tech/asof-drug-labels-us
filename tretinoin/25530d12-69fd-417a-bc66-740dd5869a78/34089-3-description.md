# DESCRIPTION

VESANOID (tretinoin) is a retinoid that induces maturation of acute promyelocytic leukemia (APL) cells in culture.
It is available in a 10 mg soft gelatin capsule for oral administration.
Each capsule also contains beeswax, butylated hydroxyanisole, edetate disodium, hydrogenated soybean oil flakes, hydrogenated vegetable oils and soybean oil.
The gelatin capsule shell contains glycerin, yellow iron oxide,red iron oxide, titanium dioxide, methylparaben and propylparaben.

Chemically, tretinoin is all-trans retinoic acid and is related to retinol (Vitamin A). It is a yellow to light orange crystalline powder with a molecular weight of 300.44.
