# DESCRIPTION

Each 5 mL of the oral solution contains:

| Oxycodone Hydrochloride, USP | 5 mg |
| --- | --- |

Each 1 mL of the oral concentrate solution contains:

| Oxycodone Hydrochloride, USP | 20 mg |
| --- | --- |
