# DESCRIPTION

VANCOCIN HCl Capsules (Vancomycin Hydrochloride Capsules, USP) contain chromatographically purified vancomycin hydrochloride, a tricyclic glycopeptide antibiotic derived from Amycolatopsis orientalis (formerly Nocardia orientalis), which has the chemical formula C66H75Cl2N9O24•HCl.
The molecular weight of vancomycin hydrochloride is 1485.73; 500 mg of the base is equivalent to 0.34 mmol.

The capsules contain vancomycin hydrochloride equivalent to 125 mg (0.08 mmol) or 250 mg (0.17 mmol) vancomycin.
The capsules also contain F D & C Blue No. 2, gelatin, iron oxide, polyethylene glycol, titanium dioxide, and other inactive ingredients.
