# 11 DESCRIPTION

DIFFERIN (adapalene) Lotion, 0.1% for topical use, is an adapalene-based product.

Adapalene is a naphthoic acid derivative with retinoid-like properties.
The chemical name for adapalene is (6-[3-(1-adamantyl)-4-meghoxyphenyl]-2-naphthoic acid).
