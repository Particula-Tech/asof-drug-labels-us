# DESCRIPTION

Hydroxychloroquine sulfate is an odorless, white or practically white crystalline powder, freely soluble in water; practically insoluble in alcohol, in chloroform, and in ether.
Chemically the drug is 2-[[4-[(7-Chloro-4-quinolyl) amino] pentyl] ethylamino] ethanol sulfate (1:1).

Each hydroxychloroquine sulfate tablet intended for oral administration contains 200 mg of hydroxychloroquine sulfate equivalent to 155 mg base.
In addition, each tablet contains the following inactive ingredients: dibasic calcium phosphate dihydrate, magnesium stearate, pregelatinized starch, polyethylene glycol, polyvinyl alcohol, starch, talc and titanium dioxide.
