# 2DOSAGE AND ADMINISTRATION

OXYTROL 3.9 mg/day should be applied to dry, intact skin on the abdomen, hip, or buttock twice weekly (every 3 or 4 days).
A new application site should be selected with each new transdermal system to avoid re-application to the same site within 7 days.
Do not divide or cut the transdermal system into pieces.
Do not use if the transdermal system is damaged.
