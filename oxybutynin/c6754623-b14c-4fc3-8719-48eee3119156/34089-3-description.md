# 11 DESCRIPTION

Oxybutynin is an antispasmodic, antimuscarinic agent.
GELNIQUE 3% is a topical, homogeneous, very lightly to moderately opalescent, translucent colorless to slightly colored gel, without particles.
The product is a hydroalcoholic gel containing 30 mg oxybutynin per gram of gel.
GELNIQUE 3% is available in a 0.92 gram (1 mL) unit dose that contains 28 mg oxybutynin.
Oxybutynin is delivered as a racemate of R- and S-isomers.
Chemically, oxybutynin base is d, l (racemic) 4-(Diethylamino)-2-butynyl (±)-α-phenylcyclohexaneglycolate.
