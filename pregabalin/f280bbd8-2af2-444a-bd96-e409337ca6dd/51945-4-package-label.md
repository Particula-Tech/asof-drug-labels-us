# PRINCIPAL DISPLAY PANEL – 82.5 mg

NDC 58151-245-93

Lyrica® CR CV (pregabalin) extended release tablets 82.5 mg

ALWAYS DISPENSE WITH MEDICATION GUIDE

30 Tablets Rx only

Store at 20°C to 25°C (68°F to 77°F); excursions permitted between 15°C and 30°C (between 59°F and 86°F).
[See USP Controlled Room Temperature].

Dispense in tight (USP), child-resistant containers.

DOSAGE AND USE See accompanying prescribing information.

Each tablet contains 82.5 mg pregabalin.
