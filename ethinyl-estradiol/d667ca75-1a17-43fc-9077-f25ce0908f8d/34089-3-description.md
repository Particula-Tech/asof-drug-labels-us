# DESCRIPTION

JinteliTM (norethindrone acetate and ethinyl estradiol tablets, USP) is a continuous dosage regimen of a progestin-estrogen combination for oral administration.

Each white tablet contains 1 mg norethindrone acetate [19-Norpregn-4-en-20-yn-3-one, 17-(acetyloxy)-, (17α)-] and 5 mcg ethinyl estradiol [19-Norpregna-1,3,5(10)-trien-20-yne-3, 17-diol, (17α)-].
Each tablet also contains the following ingredients: calcium stearate, lactose monohydrate, microcrystalline cellulose, pregelatinized starch, and sodium starch glycolate.
