# 11 DESCRIPTION

Linezolid tablets contain linezolid, which is a synthetic antibacterial agent of the oxazolidinone class.
The chemical name for linezolid is (N-[[(5S)-3-[3-Fluoro-4-(4-morpholinyl) phenyl]-2-oxo-5-oxazolidinyl]methyl] acetamide.
The empirical formula is C16H20FN3O 4.

Linezolid tablets for oral administration contain 600 mg linezolid as film-coated tablets.
Inactive ingredients are carnauba wax, colloidal silicon dioxide, hypromellose, lactose monohydrate, magnesium stearate, polacrilin potassium, polyethylene glycol and titanium dioxide.
