# 11 DESCRIPTION

Linezolid for oral suspension contains linezolid, which is a synthetic antibacterial agent of the oxazolidinone class.
The chemical name for linezolid is (S)-N-[[3-[3-Fluoro-4-(4-morpholinyl)phenyl]-2-oxo-5-oxazolidinyl] methyl]-acetamide.

The empirical formula is C16H20FN3O4.

Linezolid for oral suspension is supplied as an orange-flavored granule/powder for constitution into a suspension for oral administration.
Following constitution, each 5 mL contains 100 mg of linezolid.
Inactive ingredients are sucrose, citric acid, sodium citrate, microcrystalline cellulose and carboxymethylcellulose sodium, aspartame, xanthan gum, mannitol, sodium benzoate, colloidal silicon dioxide, sodium chloride, and flavors [see Patient Counseling Information (17)].
The sodium (Na+) content is 8.52 mg/5 mL (0.4 mEq/5 mL).
