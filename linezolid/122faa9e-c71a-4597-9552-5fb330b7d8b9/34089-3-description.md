# 11 DESCRIPTION

ZYVOX I.V.
Injection contains linezolid, which is a synthetic antibacterial agent of the oxazolidinone class.
The chemical name for linezolid is (S)-N-[[3-[3-Fluoro-4-(4-morpholinyl)phenyl]-2-oxo-5-oxazolidinyl] methyl]-acetamide.

The empirical formula is C16H20FN3O4.

ZYVOX I.V.
Injection is supplied as a ready-to-use sterile isotonic solution for intravenous infusion.
Each mL contains 2 mg of linezolid.
Inactive ingredients are citric acid, dextrose in an aqueous vehicle for intravenous administration, and sodium citrate.
Sodium hydroxide NF and/or hydrochloric acid NF are used to adjust the pH.
The sodium (Na+) content is 0.38 mg/mL (5 mEq/300 mL bag).
