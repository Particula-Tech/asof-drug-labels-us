# 11 DESCRIPTION

Linezolid tablets contain linezolid, which is a synthetic antibacterial agent of the oxazolidinone class.
The chemical name for linezolid is (S)-N-[[3-[3-Fluoro-4-(4­morpholinyl)phenyl]-2-oxo-5-oxazolidinyl] methyl]-acetamide.

The empirical formula is C16H20FN3O4.

Linezolid tablets for oral administration contain 600 mg linezolid as film-coated compressed tablets.
Inactive ingredients are microcrystalline cellulose, hydroxypropyl cellulose, low-substituted hydroxypropyl cellulose, colloidal silicon dioxide, sodium stearyl fumarate, croscarmellose sodium, hypromellose, titanium dioxide and polyethylene glycol.
The sodium (Na+) content is 2.92 mg per 600-mg tablet (0.1 mEq per tablet).
