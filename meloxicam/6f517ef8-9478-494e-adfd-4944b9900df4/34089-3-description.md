# 11 DESCRIPTION

ANJESO (meloxicam) is a nonsteroidal anti-inflammatory drug (NSAID).
It is a sterile opaque, pale-yellow, aqueous dispersion containing the active pharmaceutical ingredient meloxicam for intravenous administration.
Each mL of aqueous dispersion contains 30 mg of meloxicam, povidone, sodium deoxycholate (deoxycholic acid), sucrose, and water for injection

Meloxicam is designated chemically as 4-hydroxy-2-methyl-N-(5-methyl-2-thiazolyl)-2H-1,2-benzothiazine-3-carboxamide-1,1-dioxide.
The molecular weight is 351.4.
