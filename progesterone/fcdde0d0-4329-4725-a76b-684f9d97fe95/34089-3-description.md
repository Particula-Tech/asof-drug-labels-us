# 11 DESCRIPTION

Progesterone vaginal insert contains micronized progesterone, USP.
Progesterone vaginal insert is supplied with polyethylene vaginal applicators.

The active ingredient, progesterone, USP is present in 100 mg amount along with other excipients.
The chemical name for progesterone is pregn-4-ene-3,20-dione.
It has an molecular formula of C 21H 30O 2and a molecular weight of 314.5.
Progesterone exists in two polymorphic forms.
The form used in progesterone vaginal insert, the alpha-form, has a melting point of 127°C to 131°C.
