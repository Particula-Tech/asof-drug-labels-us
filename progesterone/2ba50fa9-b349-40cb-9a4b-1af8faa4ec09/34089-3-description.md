# 11 DESCRIPTION

ENDOMETRIN (progesterone) vaginal insert contains micronized progesterone.
ENDOMETRIN is supplied with polyethylene vaginal applicators.

The active ingredient, progesterone, is present (100 mg) along with inactive ingredients.
The chemical name for progesterone is pregn-4-ene-3,20-dione, its empirical formula is C21H30O2, its molecular weight is 314.5.
Progesterone exists in two polymorphic forms.
The form used in ENDOMETRIN, the alpha-form, has a melting point of 127-131°C.
