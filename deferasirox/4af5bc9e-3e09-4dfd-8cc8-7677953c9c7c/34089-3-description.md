# 11 DESCRIPTION

Deferasirox is an iron-chelating agent provided as a tablet for oral use.
Deferasirox is designated chemically as 4-[3,5-bis(2-hydroxyphenyl)-1H-1,2,4-triazol-1-yl]benzoic acid and has the following structural formula:

Deferasirox is a white to slightly yellow color powder.
It has a molecular formula C21H15N3O4 and molecular weight of 373.36.
It is freely soluble in dimethyl formamide, sparingly soluble in dimethylsulfoxide and practically insoluble in water with a pH of suspension of 4.1.

Each deferasirox tablet contains 90 mg, 180 mg or 360 mg deferasirox and contains following Inactive ingredients: colloidal silicon dioxide, croscarmellose sodium, hypromellose, polyethylene glycol, magnesium stearate, microcrystalline cellulose, povidone K30, poloxamer 407, talc and titanium dioxide.

Additionally, each 180 mg and 360 mg tablet contains FD&C blue # 2/Indigo Carmine Aluminum Lake; each 180 mg tablet contains iron oxide yellow and each 360 mg tablets contain D&C red #27/Phloxine Aluminum Lake.
