# 11 DESCRIPTION

Anifrolumab-fnia is a type I interferon (IFN) receptor antagonist, immunoglobulin G1 kappa (IgG1κ) monoclonal antibody that is produced in mouse myeloma cells (NS0) by recombinant DNA technology.
The molecular weight is approximately 148 kDa.

Intravenous Infusion

SAPHNELO (anifrolumab-fnia) injection is a sterile, preservative‑free, clear to opalescent, colorless to slightly yellow, solution in a single-dose vial for intravenous use.

Each 2 mL single-dose vial contains 300 mg (150 mg/mL) of anifrolumab-fnia, histidine (3 mg), L-histidine hydrochloride monohydrate (6 mg), lysine hydrochloride (18 mg), polysorbate 80 (1 mg), trehalose (89 mg), and Water for Injection, USP.
The pH is 5.9.

Subcutaneous Injection

SAPHNELO (anifrolumab-fnia) injection is a sterile, preservative-free, clear to opalescent, colorless to slightly yellow, solution in a prefilled syringe or autoinjector for subcutaneous injection.

Each 0.8 mL single-dose prefilled syringe or autoinjector delivers 120 mg of anifrolumab-fnia, histidine (1 mg), L-histidine hydrochloride monohydrate (3 mg), lysine hydrochloride (7 mg), polysorbate 80 (0.4 mg), trehalose (36 mg), and Water for Injection, USP.
The pH is 5.9.
