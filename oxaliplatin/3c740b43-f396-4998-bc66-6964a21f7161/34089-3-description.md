# DESCRIPTION

ELOXATIN® (oxaliplatin injection) is an antineoplastic agent with the molecular formula C8H14N2O4Pt and the chemical name of cis-[(1R,2R)-1,2-cyclohexanediamine-N,N'] [oxalato(2-)-O,O'] platinum.
Oxaliplatin is an organoplatinum complex in which the platinum atom is complexed with 1,2-diaminocyclohexane(DACH) and with an oxalate ligand as a leaving group.

The molecular weight is 397.3.
Oxaliplatin is slightly soluble in water at 6 mg/mL, very slightly soluble in methanol, and practically insoluble in ethanol and acetone.
