# DESCRIPTION

Triamcinolone Acetonide Cream USP contains Triamcinolone Acetonide [Pregna-1,4-diene-3,20-dione, 9-fluoro-11,21- dihydroxy-16,17-[(1-methylethylidene)bis- (oxy)]-, (11β,16α)-], with the empirical formula C24H31FO6 and molecular weight 434.50.
CAS 76-25-5.

Triamcinolone Acetonide Cream USP, 0.1% contains 1 mg Triamcinolone Acetonide per gram in a base consisting of cetyl alcohol, cetyl esters wax, glyceryl monostearate, isopropyl palmitate, polysorbate-60, polysorbate-80, propylene glycol and purified water.
