# DESCRIPTION:

TAZORAC® Gel is a translucent, aqueous gel and contains the compound tazarotene, a member of the acetylenic class of retinoids.
It is for topical dermatologic use only.
The active ingredient is represented by the following structural formula:

Chemical Name:

Ethyl 6-[2-(4,4-dimethylthiochroman-6-yl) ethynyl] nicotinate

Contains:

- Active: Tazarotene...................................
  0.05% or 0.1% (w/w) Preservative: Benzyl alcohol..................................
  1.0% (w/w)

Inactives: Ascorbic acid, butylated hydroxyanisole, butylated hydroxytoluene, carbomer 934P, edetate disodium, hexylene glycol, poloxamer 407, polyethylene glycol 400, polysorbate 40, purified water, and tromethamine.
