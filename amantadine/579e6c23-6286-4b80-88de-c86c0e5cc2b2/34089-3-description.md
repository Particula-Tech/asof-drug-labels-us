# DESCRIPTION

Amantadine hydrochloride is designated chemically as 1-adamantanamine hydrochloride.
Its molecular weight is 187.7 with a molecular formula C10H17N.HCl.

Amantadine hydrochloride, USP is a white or almost white, crystalline powder, freely soluble in water, ethanol and methanol; soluble in chloroform; sparingly soluble in methylene chloride; practically insoluble in ether.

Amantadine hydrochloride has pharmacological actions as both an anti-Parkinson and an antiviral drug.

Each amantadine hydrochloride capsule, USP intended for oral administration contains 100 mg of amantadine hydrochloride, USP.
In addition, each capsule contains the following inactive ingredients: crosscarmellose sodium, ethyl cellulose, FD&C blue #1, FD&C red #40, gelatin, magnesium stearate, microcrystalline cellulose, pregelatinized starch, sodium lauryl sulfate and titanium dioxide.
Each capsule is printed with white pharmaceutical ink which contains potassium hydroxide, shellac and titanium dioxide.
