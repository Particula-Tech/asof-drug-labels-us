# 11 DESCRIPTION

VERSACLOZ, an atypical antipsychotic drug, is a tricyclic dibenzodiazepine derivative, 8-chloro-11-(4-methyl-1-piperazinyl)-5H-dibenzo[b,e][1,4]diazepine.

The is:

VERSACLOZ is available as a free-flowing yellow suspension.
Each mL contains 50 mg of clozapine.

The active component of VERSACLOZ is clozapine.
The remaining components are glycerin, sorbitol (crystallizing), sodium dihydrogen phosphate dihydrate, xanthan gum, sodium methylparaben, sodium propylparaben, povidone, water, and sodium hydroxide to adjust to a pH range of 6.5 – 7.0.
