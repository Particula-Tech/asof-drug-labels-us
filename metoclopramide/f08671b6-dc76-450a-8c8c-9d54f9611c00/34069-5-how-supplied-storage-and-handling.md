# HOW SUPPLIED

Each white, capsule-shaped scored reglan® tablet (metoclopramide tablets, USP) contains 10 mg metoclopramide base (as the monohydrochloride monohydrate).
Available in:

Bottles of 100 tablets (NDC 68220-151-10)

Each green, elliptical-shaped reglan® tablet (metoclopramide tablets, USP) contains 5 mg metoclopramide base (as the monohydrochloride monohydrate).
Available in:

Bottles of 100 tablets (NDC 68220-150-10)

Dispense tablets in tight, light-resistant container.

Tablets should be stored at controlled room temperature, between 20°C and 25°C (68°F and 77°F).
