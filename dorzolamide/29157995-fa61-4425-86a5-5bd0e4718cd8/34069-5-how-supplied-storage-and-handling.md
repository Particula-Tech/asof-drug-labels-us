# HOW SUPPLIED

Dorzolamide Hydrochloride Ophthalmic Solution is a slightly opalescent, nearly colorless, slightly viscous solution.

Dorzolamide Hydrochloride Ophthalmic Solution is supplied in a white LDPE plastic DROP-TAINER® bottle, a white dropper tip and an orange polypropylene cap as follows:

5mL, in an 8mL capacity bottle NDC 61314-019-05

10mL, in a 10mL capacity bottle NDC 61314-019-10

## Storage

Store Dorzolamide Hydrochloride Ophthalmic Solution at 2°-25°C (36°-77°F).
Protect from light.
