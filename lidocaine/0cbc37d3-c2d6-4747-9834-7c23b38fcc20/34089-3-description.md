# DESCRIPTION

Lidocaine Hydrochloride Jelly USP, 2% is a sterile aqueous product that contains a local anesthetic agent and is administered topically (see INDICATIONS AND USAGE for specific uses).

Lidocaine Hydrochloride Jelly USP, 2% contains lidocaine hydrochloride which is chemically designated as acetamide, 2-(diethylamino)-N-(2,6-dimethylphenyl)-, monohydrochloride and has the following structural formula:

Lidocaine Hydrochloride Jelly USP, 2% also contains sodium carboxymethylcellulose, and the resulting mixture maximizes contact with mucosa and provides lubrication for instrumentation.
The unused portion should be discarded after initial use.

Composition of Lidocaine Hydrochloride Jelly USP, 2%: Each mL contains 20 mg of lidocaine HCI.
The formulation also contains sodium carboxymethylcellulose and sodium hydroxide and/or hydrochloric acid to adjust pH between 6.0 to 7.0.
