# 16. HOW SUPPLIED/STORAGE AND HANDLING

NDC 70645-123-26 ZINGO® (lidocaine hydrochloride monohydrate) powder intradermal injection system contains 0.5mg of sterile lidocaine hydrochloride monohydrate.
ZINGO® is a single-use device packaged in an individual clear pouch and is stored at controlled room temperature (15–30°C, 59–86°F).
