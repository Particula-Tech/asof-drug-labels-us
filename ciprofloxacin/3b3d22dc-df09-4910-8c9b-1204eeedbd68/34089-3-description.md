# 11 DESCRIPTION

Ciprofloxacin tablets, USP (ciprofloxacin hydrochloride) are synthetic antimicrobial agents for oral administration.
Ciprofloxacin hydrochloride, USP, a fluoroquinolone, is the monohydrochloride monohydrate salt of 1-cyclopropyl-6-fluoro-1, 4-dihydro-4-oxo-7-(1-piperazinyl)-3quinolinecarboxylic acid.
It is a faintly yellowish to light yellow crystalline substance with a molecular weight of 385.8.
