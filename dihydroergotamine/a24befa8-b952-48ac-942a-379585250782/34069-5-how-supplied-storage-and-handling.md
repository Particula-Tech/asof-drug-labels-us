# HOW SUPPLIED

Migranal® (dihydroergotamine mesylate, USP) Nasal Spray is available (as a clear, colorless to faintly yellow solution) in 3.5 mL amber glass vials containing 4 mg of dihydroergotamine mesylate, USP.

Migranal® (dihydroergotamine mesylate, USP) Nasal Spray is provided as a package of 8 units, administration instruction sheet, and one package insert.
Each unit consists of one vial and one sprayer.
(NDC 0187-0245-03)

Store below 25°C (77°F).
Do not refrigerate or freeze.
