# DESCRIPTION

Migranal® is ergotamine hydrogenated in the 9,10 position as the mesylate salt.
Migranal® is known chemically as ergotaman-3', 6', 18-trione, 9,10-dihydro-12'-hydroxy-2'-methyl-5'- (phenylmethyl)-, (5'α)-, monomethanesulfonate.
