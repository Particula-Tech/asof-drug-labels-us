# DESCRIPTION

Dihydroergotamine mesylate is ergotamine hydrogenated in the 9,10 position as the mesylate salt.
Dihydroergotamine mesylate is known chemically as ergotaman-3', 6', 18-trione, 9,10-dihydro-12'-hydroxy-2'-methyl-5'- (phenylmethyl)-, (5'α)-, monomethane-sulfonate.
Its molecular weight is 679.78 and its empirical formula is C 33H 37N 5O 5•CH 4O 3S.
