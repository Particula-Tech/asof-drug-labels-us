# 16 HOW SUPPLIED/STORAGE AND HANDLING

Varenicline tablets is supplied for oral administration in two strengths: a 0.5 mg capsular biconvex, white to off-white, film-coated tablet debossed with "VC" on one side and "0.5" on the other side and a 1 mg capsular biconvex, light blue film-coated tablet debossed with "VC" on one side and "1" on the other side.
Varenicline tablets is supplied in the following package configurations:

|  | Description | NDC |
| --- | --- | --- |
| Packs | Starting 4-week card: 0.5 mg x 11 tablets and 1 mg x 42 tablets | NDC 67877- 745-54 |
|  | Continuing 4-week card: 1 mg x 56 tablets | NDC 67877- 744-54 |
|  | Starting Month Box: 0.5 mg x 11 tablets and 1 mg x 42 tablets | NDC 67877- 745-54 |
|  | Continuing Month Box: 1 mg x 56 tablets | NDC 67877- 744-54 |
| Bottles | 0.5 mg - bottle of 56 | NDC 67877-743-95 |
| 1 mg - bottle of 56 | NDC 67877-744-95 |  |

Store at 20°C to 25°C (68°F to 77°F); excursions permitted to 15 to 30ºC (59 and 86ºF) (see USP Controlled Room Temperature).
Protect from light.
