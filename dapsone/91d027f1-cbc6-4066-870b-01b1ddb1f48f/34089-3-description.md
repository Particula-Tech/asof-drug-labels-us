# 11 DESCRIPTION

Dapsone gel, 5%, contains dapsone, USP a sulfone, in an aqueous gel base for topical dermatologic use.
Dapsone gel, 5% is a gritty translucent material with visible drug substance particles.
Chemically, dapsone has an empirical formula of C 12H 12N 2O 2S.
It is a white, odorless crystalline powder that has a molecular weight of 248.
