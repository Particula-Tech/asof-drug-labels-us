# 16 HOW SUPPLIED/STORAGE AND HANDLING

ACZONE (dapsone) Gel, 5%, is supplied in the following size tubes:

NDC 16110-367-60 60 gram laminate tube

NDC 16110-367-90 90 gram laminate tube

Store ACZONE gel at controlled room temperature, 20°-25℃ (68°-77℉), excursions permitted to 15°-30℃ (59°-86℉).
Protect from freezing.
