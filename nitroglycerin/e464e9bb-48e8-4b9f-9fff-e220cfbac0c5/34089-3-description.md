# DESCRIPTION

Nitroglycerin is 1,2,3-propanetriol trinitrate, an organic nitrate whose structural formula is:

and whose molecular weight is 227.09.
The organic nitrates are vasodilators, active on both arteries and veins.

NITRO-BID® for topical use contains lactose and 2% nitroglycerin in a base of lanolin, white petrolatum and purified water.
Each inch (2.5 cm), as squeezed from the tube, contains approximately 15 mg of nitroglycerin.
