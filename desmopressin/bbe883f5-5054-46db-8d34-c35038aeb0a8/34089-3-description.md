# DESCRIPTION

Stimate® (desmopressin acetate) is a synthetic analogue of the natural pituitary hormone 8-arginine vasopressin (ADH), an antidiuretic hormone affecting renal water conservation.
Stimate® Nasal Spray contains 1.5 mg/mL desmopressin acetate in a pH-adjusted aqueous solution with chlorobutanol and sodium chloride as inactive ingredients.
Stimate® Nasal Spray's compression pump delivers 0.1 mL (150 µg) of solution per spray.
It is chemically defined as follows:
