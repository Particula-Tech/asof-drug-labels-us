# HOW SUPPLIED

AVAPRO® (irbesartan) is available as white to off-white biconvex oval tablets, debossed with a heart shape on one side and a portion of the NDC code on the other.
Unit-of-use bottles contain 30, 90, or 500 tablets and blister packs contain 100 tablets, as follows:

## Storage

Store at 25° C (77° F); excursions permitted to 15° C - 30° C (59° F - 86° F) [see USP Controlled Room Temperature].
