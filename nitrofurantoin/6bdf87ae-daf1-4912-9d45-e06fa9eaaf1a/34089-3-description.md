# DESCRIPTION

Furadantin (nitrofurantoin), a synthetic chemical, is a stable, yellow, crystalline compound.
Furadantin is an antibacterial agent for specific urinary tract infections.
Furadantin is available in 25mg/5mL liquid suspension for oral administration.

## Inactive Ingredients

Furadantin Oral Suspension contains carboxymethylcellulose sodium, citric acid, flavors, glycerin, magnesium aluminum silicate, methylparaben, propylparaben, purified water, saccharin, sodium citrate, and sorbitol.
