# DESCRIPTION

Nitrofurantoin a synthetic chemical, is a stable, yellow, crystalline compound.
Nitrofurantoin is an antibacterial agent for specific urinary tract infections.
Nitrofurantoin is available in 25 mg/5 mL liquid suspension for oral administration.
Inactive Ingredients Nitrofurantoin Oral Suspension contains carboxymethylcellulose sodium, citric acid, flavors, glycerin, magnesium aluminum silicate, methylparaben, propylparaben, purified water, sodium citrate, and sorbitol.
