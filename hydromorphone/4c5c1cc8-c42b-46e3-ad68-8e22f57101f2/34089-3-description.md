# DESCRIPTION

Hydromorphone Hydrochloride Tablets USP, 8 mg are supplied in tablet form for oral administration.

Hydromorphone hydrochloride, a hydrogenated ketone of morphine, is an opioid analgesic.

The chemical name of Hydromorphone Hydrochloride Tablets is 4,5α-epoxy-3-hydroxy-17-methylmorphinan-6-one hydrochloride.
