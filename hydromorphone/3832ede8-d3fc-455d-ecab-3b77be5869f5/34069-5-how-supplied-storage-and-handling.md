# HOW SUPPLIED

Hydromorphone hydrochloride injection, USP (high potency formulation) contains 10 mg hydromorphone hydrochloride per mL with 0.2% sodium citrate and 0.2% citric acid solution.
No added preservative.
It is supplied as:

| HIGHPOTENCY: | 10 mg/1 mL Box of 10 vials NDC 0409-2634-01 |
| --- | --- |
| *50 mg/5 mL Box of 10 vials NDC 0409-2634-05 |  |
| *500 mg/50 mL Single dose vial NDC 0409-2634-50 |  |
| * DILUTE PRIOR TO USE. FOR USE IN THE PREPARATION OF LARGE VOLUME PARENTERAL SOLUTIONS. |  |

STORAGE: Parenteral forms of hydromorphone hydrochloride injection should be stored at 20 to 25°C (68 to 77°F).
[See USP Controlled Room Temperature.]

Protect from light.
