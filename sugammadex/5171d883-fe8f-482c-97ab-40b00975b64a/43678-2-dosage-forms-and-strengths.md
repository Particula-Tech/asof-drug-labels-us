# 3 DOSAGE FORMS AND STRENGTHS

BRIDION (sugammadex) injection is a sterile, clear, colorless to slightly yellow-brown, non-pyrogenic aqueous solution intended for intravenous infusion.
BRIDION is available as follows:

- 200 mg/2 mL (100 mg/mL) in a single-dose vial for bolus injection
- 500 mg/5 mL (100 mg/mL), in a single-dose vial for bolus injection
