# 3 DOSAGE FORMS AND STRENGTHS

Sugammadex injection is a clear, colorless to slightly yellow-brown color solution for intravenous infusion.
Sugammadex injection is available as follows: • 200 mg/2 mL (100 mg/mL) in a single-dose vial for bolus injection • 500 mg/5 mL (100 mg/mL), in a single-dose vial for bolus injection
