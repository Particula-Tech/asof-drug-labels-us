# 11 DESCRIPTION

Dapagliflozin, an inhibitor of SGLT2, is described chemically as (lS)-1,5-Anhydro-1-C-[4-chloro-3-[(4-ethoxyphenyl)methyl] phenyl]-D-glucitol.
The molecular formula is C21H25ClO6 and the molecular weight is 408.88.

Dapagliflozin tablets are available for oral administration containing 5 mg dapagliflozin or 10 mg dapagliflozin, and the following inactive ingredients: croscarmellose sodium, hypromellose, lactose monohydrate, magnesium stearate and microcrystalline cellulose.
In addition, the film coating contains the following inactive ingredients: ferric oxide yellow, hydroxypropyl cellulose, hypromellose, titanium dioxide and triethyl citrate.
