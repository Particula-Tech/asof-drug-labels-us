# 11 DESCRIPTION

Denosumab-mobz is a human IgG2 monoclonal antibody that binds to human RANKL.
Denosumab has an approximate molecular weight of 147 kDa and is produced in genetically engineered mammalian (Chinese hamster ovary) cells.

Oziltus (denosumab-mobz) injection is a sterile, preservative-free, clear, colorless to pale yellow solution.

Each single-dose vial contains 1.7 mL solution of 120 mg denosumab, glacial acetic acid (1.84 mg), polysorbate 20 (0.17 mg), sorbitol (78.20 mg), Water for Injection (USP), and sodium hydroxide to adjust the pH to 5.2.
