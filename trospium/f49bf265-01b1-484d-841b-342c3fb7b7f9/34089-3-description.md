# DESCRIPTION

SANCTURA® (trospium chloride) is a quaternary ammonium compound with the chemical name of spiro[8-azoniabicyclo[3,2,1]octane-8,1'-pyrrolidinium]-3-[(hydroxydiphenyl-acetyl)-oxy]chloride(1α, 3β, 5α)-(9Cl).
The empirical formula of trospium chloride is C25H30ClNO3 and its molecular weight is 427.97.

Trospium chloride is a fine, colorless to slightly yellow, crystalline solid.
The compound's solubility in water is approximately 1 g/2 mL.

Each SANCTURA® tablet contains 20 mg of trospium chloride and is to be given orally.
Each tablet also contains the following inactive ingredients: sucrose, wheat starch, microcrystalline cellulose, talc, lactose monohydrate, calcium carbonate, titanium dioxide, stearic acid, croscarmellose sodium, povidone, polyethylene glycol 8000, colloidal silicon dioxide, ferric oxide, carboxymethylcellulose sodium, white wax, magnesium stearate, and carnauba wax.
