# 11 DESCRIPTION

Trospium chloride is a quaternary ammonium compound with the chemical name of Spiro[8-azoniabicyclo[3.2.1]octane-8,1'-pyrrolidinium], 3-[(hydroxydiphenylacetyl)oxy]-, chloride, (1α, 3β, 5α).
The empirical formula of trospium chloride is C25H30ClNO3 and its molecular weight is 427.97.

Trospium chloride is a fine, colorless to slightly yellow, crystalline solid.
The compound's solubility in water is approximately 1 g per 2 mL.

Each Trospium Chloride Tablet contains 20 mg of trospium chloride, a muscarinic antagonist, for oral administration.
Each tablet also contains the following inactive ingredients: microcrystalline cellulose, lactose monohydrate, calcium carbonate, croscarmellose sodium, povidone, hypromellose, talc, stearic acid, titanium dioxide, colloidal silicon dioxide, magnesium stearate and polyethylene glycol 3350.
