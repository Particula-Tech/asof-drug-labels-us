# 11 DESCRIPTION

Trospium chloride, USP is a quaternary ammonium compound with the chemical name of Spiro[8azoniabicyclo[3.2.1]octane-8,1'-pyrrolidinium], 3-[(hydroxydiphenylacetyl)oxy]-, chloride, (1α, 3β, 5α).
The empirical formula of trospium chloride, USP is C25H30ClNO3 and its molecular weight is 427.97.

Trospium chloride, USP is a fine, colorless to slightly yellow, crystalline solid.
The compound’s solubility in water is approximately 1 g per 2 mL.

Each trospium chloride tablet contains 20 mg of trospium chloride, USP a muscarinic antagonist, for oral administration.
Each tablet also contains the following inactive ingredients: lactose monohydrate, microcrystalline cellulose, croscarmellose sodium, colloidal silicon dioxide, magnesium stearate, hypromellose 2910, titanium dioxide, polyethylene glycol 400, polysorbate 80, xylitol, sucralose, red iron oxide and yellow iron oxide.
