# DESCRIPTION

Minocycline hydrochloride, USP is a semisynthetic derivative of tetracycline, 4,7- Bis(dimethylamino)-1,4,4a,5,5a,6,11,12a-octahydro-3,10,12,12a-tetrahydroxy-1,11-dioxo-2-naphthacenecarboxamide monohydrochloride.

Minocycline hydrochloride tablets, USP for oral administration, contains minocycline hydrochloride, USP equivalent to 50 mg, 75 mg or 100 mg of minocycline.
In addition, each film-coated tablet contains the following inactive ingredients: colloidal silicon dioxide, crospovidone, hypromellose, iron oxide yellow, lactose monohydrate, magnesium stearate, polyethylene glycol 6000, silicified microcrystalline cellulose, stearic acid, and titanium dioxide.
