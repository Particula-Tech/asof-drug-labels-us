# DESCRIPTION

Lorazepam Tablets, USP, an antianxiety agent, has the chemical formula, 7-Chloro-5-(2-chlorophenyl)-1,3-dihydro-3-hydroxy-2 H-1,4-benzodiazepin-2-one:

C 15H 10Cl 2N 2O 2 MW: 321.16

It is a white or almost white crystalline powder almost insoluble in water.
Each Lorazepam Tablet, USP, to be taken orally, contains 0.5 mg, 1 mg, or 2 mg of Lorazepam, USP.
The inactive ingredients present are croscarmellose sodium, magnesium stearate, microcrystalline cellulose, sodium lauryl sulfate and tribasic calcium phosphate.
