# DESCRIPTION

Lorazepam USP, an antianxiety agent, has the chemical formula, 2H-1,4-benzodiazepin-2-one, 7-chloro-5-(2-chlorophenyl)-1,3-dihydro-3-hydroxy-, (±)-:

C15H10Cl2N2O2 M.W.
321.16

Lorazepam, USP is a white to almost white powder, practically insoluble in water.
Each mL of lorazepam oral concentrate, USP contains 2 mg of lorazepam.
The inactive ingredients are polyethylene glycol, propylene glycol and triacetin.
