# DESCRIPTION

Ativan (lorazepam), an antianxiety agent, has the chemical formula, 7-chloro-5-(o-chlorophenyl)-1,3-dihydro-3-hydroxy-2 H-1,4-benzodiazepin-2-one:

C 15H 10Cl 2N 2O 2 M.W.
321.16

It is a nearly white powder almost insoluble in water.
Each Ativan (lorazepam) tablet, to be taken orally, contains 0.5 mg, 1 mg, or 2 mg of lorazepam.
The inactive ingredients present are lactose monohydrate, magnesium stearate, microcrystalline cellulose, and polacrilin potassium.
