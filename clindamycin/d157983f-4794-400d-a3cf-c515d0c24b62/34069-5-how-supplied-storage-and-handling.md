# HOW SUPPLIED

Each mL of CLEOCIN PHOSPHATE Sterile Solution contains clindamycin phosphate equivalent to 150 mg clindamycin, 0.5 mg disodium edetate,; 9.45 mg benzyl alcohol added as preservative.
When necessary, pH is adjusted with sodium hydroxide and/or hydrochloric acid.
