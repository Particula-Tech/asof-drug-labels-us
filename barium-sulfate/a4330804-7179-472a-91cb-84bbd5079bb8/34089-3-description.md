# 11 DESCRIPTION

E-Z-HD (barium sulfate) is a radiographic contrast agent that is supplied as a fine white powder for oral suspension (98%w/w barium sulfate) for oral administration.
It is designated chemically as BaSO4 with a molecular weight of 233.43 g/mol, and a density of 4.5 g/cm3.
