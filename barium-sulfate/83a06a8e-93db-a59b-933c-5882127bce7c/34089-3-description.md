# 11 DESCRIPTION

ENTERO VU 24% (barium sulfate) is a radiographic contrast agent that is supplied as a suspension (24% w/v) for oral administration.
The active ingredient barium sulfate is designated chemically as BaSO4 with a molecular weight of 233.4 g/mol, a density of 4.5 g/cm3, and the following chemical structure

ENTERO VU 24% contains the following excipients: acacia, carrageenan, citric acid, methylcellulose, natural and artificial blueberry flavor, polysorbate 80, potassium chloride, potassium sorbate, purified water, saccharin sodium, simethicone emulsion, sodium benzoate, sodium citrate, sorbitol solution, and xanthan gum.
