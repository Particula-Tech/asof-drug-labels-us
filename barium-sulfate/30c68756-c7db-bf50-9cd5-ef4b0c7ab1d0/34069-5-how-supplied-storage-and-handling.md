# 16 HOW SUPPLIED/STORAGE AND HANDLING

## 16.1 How Supplied

TAGITOL V (barium sulfate) is an oral suspension (40% w/v) supplied as a box of three 20 mL HDPE bottles.
Each bottle contains 8 grams barium sulfate.

Provided as: 24 boxes, each containing 3 (20 mL) bottles (NDC 32909-814)

## 16.2 Storage and Handling

Store at USP controlled room temperature 20 to 25°C (68 to 77° F). Protect from freezing.
