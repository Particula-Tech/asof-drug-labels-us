# DESCRIPTION

Clonazepam Tablets USP, a benzodiazepine, is available as scored tablets containing 0.5 mg of clonazepam and unscored tablets containing 1 mg or 2 mg of clonazepam.
Each tablet also contains colloidal silicon dioxide, croscarmellose sodium, lactose monohydrate, magnesium stearate and microcrystalline cellulose, with the following colorants: 0.5 mg – D&C Yellow #10 aluminum lake; 1 mg – FD&C Blue #1 aluminum lake.

Chemically, clonazepam is 5-(2-chlorophenyl)-1,3-dihydro-7-nitro-2H-1,4-benzodiazepin-2-one.
It is a light yellow crystalline powder.
