# 11 DESCRIPTION

Dexmethylphenidate Hydrochloride Extended-release Capsules contains dexmethylphenidate hydrochloride, a CNS stimulant.
Dexmethylphenidate hydrochloride is the d-threoenantiomer of racemic methylphenidate hydrochloride.
Dexmethylphenidate Hydrochloride Extended-release Capsules is an extended-release formulation of dexmethylphenidate with a bi-modal release profile.
Each bead-filled dexmethylphenidate hydrochloride extended-release capsule contains half the dose as immediate-release beads and half as enteric-coated, delayed-release beads, thus providing an immediate release of dexmethylphenidate and a delayed release of dexmethylphenidate.
Dexmethylphenidate Hydrochloride Extended-release Capsules is intended for oral administration and is available as 15 mg and 30 mg extended-release capsules.
