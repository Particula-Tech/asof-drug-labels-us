# DESCRIPTION

Each yellow, capsule-shaped tablet contains 1 g Methenamine Hippurate, USP which is the hippuric acid salt of methenamine (hexamethylene tetramine).
The tablet also contains inactive ingredients: FD&C Yellow No. 5 (tartrazine, seePRECAUTIONS), magnesium stearate, povidone, and saccharin sodium.
