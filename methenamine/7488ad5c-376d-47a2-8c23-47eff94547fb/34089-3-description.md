# DESCRIPTION

Each yellow capsule-shaped tablet contains 1 g Methenamine Hippurate which is the Hippuric Acid Salt of Methenamine (hexamethylene tetramine).
The tablet also contains inactive ingredients.
FD&C Yellow No. 5 (tartrazine, see PRECAUTIONS), Magnesium Stearate, Povidone, and Saccharin Sodium.
