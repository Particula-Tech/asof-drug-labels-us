# DESCRIPTION

Methenamine Hippurate Tablets, USP is a urinary tract antiseptic drug.
Each peach color, capsule-shaped bi-convex tablet contains 1 g methenamine hippurate which is the hippuric acid salt of methenamine (hexamethylene tetramine).
The tablet also contains inactive ingredients FD&C Yellow No. 6, Magnesium Stearate, Colloidal Silicon Dioxide, Povidone, and Saccharin Sodium.
