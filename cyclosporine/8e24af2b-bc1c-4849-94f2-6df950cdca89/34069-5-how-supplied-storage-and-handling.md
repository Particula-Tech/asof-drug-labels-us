# HOW SUPPLIED

RESTASIS® ophthalmic emulsion is packaged in single use vials.
Each vial contains 0.4 mL fill in a 0.9 mL LDPE vial; 30 vials are packaged in a polypropylene tray with an aluminum peelable lid.
The entire contents of each tray (30 vials) must be dispensed intact.
RESTASIS® is also provided in a 60 count (2 x 30) package (one month supply) that must be dispensed intact.

30 Vials 0.4 mL each - NDC 0023-9163-30 60 (2 x 30) Vials 0.4 mL each - NDC 0023-9163-60

Storage: Store RESTASIS® ophthalmic emulsion at 15 - 25° C (59 - 77° F).

KEEP OUT OF THE REACH OF CHILDREN.
