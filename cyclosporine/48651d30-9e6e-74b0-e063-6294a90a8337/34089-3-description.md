# 11 DESCRIPTION

Verkazia (cyclosporine ophthalmic emulsion) 0.1% contains a topical calcineurin inhibitor immunosuppressant.
Cyclosporine is a white or almost white powder.
Cyclosporine’s chemical name is Cyclo[[(E)-(2 S,3 R,4 R)-3-hydroxy-4-methyl-2-(methylamino)-6-octenoyl]-L-2-aminobutyryl- N-methylglycyl- N-methyl-L-leucyl-L-valyl- N-methyl-L-leucyl-L-alanyl-D-alanyl- N-methyl-L-leucyl- N-methyl-L-leucyl- N-methyl-L-valyl] and it has the following structure:

Structural Formula

Formula: C 62H 111N 11O 12Mol.
Wt.: 1202.61

Verkazia ophthalmic emulsion is a sterile, unpreserved topical emulsion.
It appears as a milky-white homogeneous emulsion.
It has an osmolality of approximately 265 mOsmol/kg and a pH of 5-7.
Each mL of Verkazia ophthalmic emulsion contains: Active: Cyclosporine 1 mg/mL.
Inactives: Cetalkonium chloride, Glycerol, Medium-chain triglycerides, Poloxamer 188, Sodium Hydroxide to adjust pH, Tyloxapol and Water for Injection.
