# 11 DESCRIPTION

CEQUA (cyclosporine ophthalmic solution) 0.09% contains a topical calcineurin inhibitor immunosuppressant.
Cyclosporine’s chemical name is Cyclo[[(E)-(2S,3R,4R)-3-hydroxy-4-methyl-2-(methylamino)-6-octenoyl]-L-2-aminobutyryl-N-methylglycyl-N-methyl-L-leucyl-L-valyl-N-methyl-L-leucyl-L-alanyl-D-alanyl-N-methyl-L-leucyl-N-methyl-L-leucyl-N-methyl-L-valyl] and it has the following structure:

Structural Formula

Formula: C62H111N11O12 Mol.
Wt.: 1202.6

Cyclosporine is a white powder that is insoluble in water.
CEQUA is supplied as a sterile, clear, colorless ophthalmic solution for topical ophthalmic use.
It has an osmolality of 160 to 190 mOsmol/kg and a pH of 6.5-7.2.
Each mL of CEQUA contains:

- •Active: cyclosporine 0.09%
- •Inactives: polyoxyl hydrogenated castor oil, Octoxynol-40, polyvinylpyrrolidone, sodium phosphate monobasic dihydrate, sodium phosphate dibasic anhydrous, water for injection, and sodium hydroxide or hydrochloric acid to adjust pH.
