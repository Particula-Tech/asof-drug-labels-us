# 11 DESCRIPTION

Each Delzicol (mesalamine) delayed-release capsule for oral administration contains 400 mg of mesalamine, an aminosalicylate.
Mesalamine is a non-steroidal anti-inflammatory agent.
Delzicol (mesalamine) delayed-release capsules contain acrylic based resin, Eudragit S (methacrylic acid copolymer type B, NF), which dissolves at pH 7 or greater and releases mesalamine in the terminal ileum and beyond for topical anti-inflammatory action in the colon.
