# 11 DESCRIPTION

Each Asacol (mesalamine) delayed-release tablet for oral administration contains 400 mg of mesalamine, an aminosalicylate.
Asacol (mesalamine) Delayed-Release Tablets contain acrylic based resin, Eudragit S (methacrylic acid copolymer type B, NF), which dissolves at pH 7 or greater and releases mesalamine in the terminal ileum and beyond for topical anti-inflammatory action in the colon.
Mesalamine (also referred to as 5-aminosalicylic acid or 5-ASA) has the chemical name 5-amino-2-hydroxybenzoic acid.
