# DESCRIPTION

The active ingredient in CANASA® 1000 mg suppositories is mesalamine, also known as mesalazine or 5-aminosalicylic acid (5-ASA).
Chemically, mesalamine is 5-amino-2-hydroxybenzoic acid, and is classified as an anti-inflammatory drug.
