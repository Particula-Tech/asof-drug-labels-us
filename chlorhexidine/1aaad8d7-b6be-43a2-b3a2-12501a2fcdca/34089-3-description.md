# DESCRIPTION

PerioGard® (Chlorhexidine Gluconate Oral rinse USP, 0.12%) is an oral rinse containing 0.12% chlorhexidine gluconate (1,1'-hexamethylene bis [5-(p-chlorophenyl) biguanide] di-D-gluconate) in a base containing water, propylene glycol, glycerin, sorbitol, polyoxyl 40 hydrogenated castor oil, flavor, cetylpyridinium chloride, and FD&C blue no. 1.
PerioGard® product is a near neutral solution (pH range 5-7).
Chlorhexidine gluconate is a salt of chlorhexidine and gluconic acid.
