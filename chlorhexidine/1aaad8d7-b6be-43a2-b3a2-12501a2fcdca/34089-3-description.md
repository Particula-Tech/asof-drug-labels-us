# DESCRIPTION

PerioGard® is an oral rinse containing 0.12% chlorhexidine gluconate [N,N"-bis (4-chlorophenyl)-3,12-diimino-2,4,11,13-tetraazatetradecanediimidamide di-D-gluconate] in a base containing water, glycerin, sorbitol, PEG-40 hydrogenated castor oil, flavor, citric acid, and FD&C blue no.1.
PerioGard® oral rinse is a near-neutral solution (pH range 5-7).
Chlorhexidine gluconate is a salt of chlorhexidine and gluconic acid, with a molecular formula of C22H30C12N10∙2C6H207 and a molecular weight calculated to be 897.77.
