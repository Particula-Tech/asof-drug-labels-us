# DESCRIPTION:

Peridex™ (Chlorhexidine Gluconate 0.12%) Oral Rinse is an oral rinse containing 0.12% chlorhexidine gluconate (1, 11-hexamethylene bis [5-(p-chlorophenyl) biguanide] di-D-gluconate) in a base containing water, 11.6% alcohol, glycerin, PEG-40 sorbitan diisostearate, flavor, sodium saccharin, and FD&C Blue No. 1.
Peridex is a near-neutral solution (pH range 5-7).
Chlorhexidine gluconate is a salt of chlorhexidine and gluconic acid.
