# DESCRIPTION

Chlorhexidine gluconate oral rinse USP, 0.12% is an oral rinse containing 0.12% chlorhexidine gluconate (1,1’-hexamethylene bis [5-(p-chlorophenyl) biguanide]di-D-gluconate) in a base containing 11.6% alcohol, FD&C Blue No. 1, glycerin, peppermint flavor, polysorbate 80, purified water, and saccharin sodium.
Chlorhexidine Gluconate Oral Rinse, 0.12% is a near-neutral solution (pH range 5-7).
Chlorhexidine gluconate is a salt of chlorhexidine and gluconic acid.
Its chemical structure is:

C 22H30Cl2N10•2C6H12O7 M.W.
