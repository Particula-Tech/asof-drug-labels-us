# 11 DESCRIPTION

ENBUMYST contains bumetanide, a loop diuretic.
Chemically, bumetanide is 3-(butylamino)-4-phenoxy-5-sulfamoylbenzoic acid.

ENBUMYST is supplied as a unit-dose nasal spray containing 0.5 mg of bumetanide (equivalent to about 0.554 mg of potassium salt of bumetanide) per 0.1 mL.
ENBUMYST contains the following inactive ingredients: benzyl alcohol (0.5 mg per 0.1 mL spray), carboxymethylcellulose sodium (viscosity control agent), mannitol, potassium hydroxide (pH modifier), hydrochloric acid (to adjust pH) and water for injection.
