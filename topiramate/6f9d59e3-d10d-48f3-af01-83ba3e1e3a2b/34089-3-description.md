# DESCRIPTION

Topiramate is a sulfamate-substituted monosaccharide.

Topiramate, USP is a white to off-white crystalline powder.
It is soluble in 10 % ethanol.
Topiramate has the molecular formula C12H21NO8S and a molecular weight of 339.37.

Each topiramate capsule (sprinkle) intended for oral administration contains 15 mg or 25 mg of topiramate.
In addition, each capsule contains the following inactive ingredients: cellulose acetate, gelatin, hydroxypropyl methylcellulose, povidone, sodium lauryl sulfate, sugar spheres, talc and titanium dioxide.
Each capsule is printed with black pharmaceutical ink.
