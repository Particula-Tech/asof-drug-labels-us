# 16 HOW SUPPLIED/STORAGE AND HANDLING

How Supplied

Cefepime for injection is supplied as follows: Cefepime for Injection in the dry state, is a white to pale yellow powder.
Constituted solution of Cefepime for Injection can range in color from pale yellow to amber.

Storage and Handling

Cefepime for Injection in the dry state should be stored at 20 to 25° C (68 to 77° F) [see USP controlled room temperature.] and protected from light.
