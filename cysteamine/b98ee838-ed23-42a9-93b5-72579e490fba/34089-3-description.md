# 11 DESCRIPTION

CYSTARAN is a sterile ophthalmic solution containing 6.5 mg/mL of cysteamine hydrochloride, equivalent to 4.4 mg/mL of cysteamine (0.44%) as the active ingredient.
Cysteamine is a cystine-depleting agent which lowers the cystine content of cells in patients with cystinosis.

Molecular Formula: C2H7NS HCl Molecular Weight: 113.61

Each milliliter of CYSTARAN contains: Active: cysteamine 4.4 mg (equivalent to cysteamine hydrochloride 6.5 mg); Preservative: benzalkonium chloride 0.1 mg; Inactive Ingredients: sodium chloride, hydrochloric acid and/or sodium hydroxide (to adjust pH to 4.1-4.5), and purified water.
