# 3 DOSAGE FORMS AND STRENGTHS

VENTOLIN HFA is an inhalation aerosol.
Each actuation contains 108 mcg albuterol sulfate (90 mcg albuterol base) from the mouthpiece.
VENTOLIN HFA is supplied as an 18-g pressurized aluminum canister with dose counter fitted with a blue plastic actuator and a blue strapcap.
Each canister contains 200 actuations.
