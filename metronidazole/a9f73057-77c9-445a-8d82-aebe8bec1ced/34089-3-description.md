# DESCRIPTION

METROGEL® Topical Gel contains metronidazole, USP, at a concentration of 7.5 mg per gram (0.75%) in a gel consisting of carbomer 940, edetate disodium, methylparaben, propylene glycol, propylparaben, purified water, and sodium hydroxide.
Metronidazole is classified therapeutically as an antiprotozoal and antibacterial agent.
