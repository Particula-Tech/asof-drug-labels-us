# DESCRIPTION

FLAGYL tablets contain 250 mg or 500 mg of metronidazole USP.
Inactive ingredients include cellulose, FD&C Blue No. 2 Lake, hydroxypropyl cellulose, hypromellose, polyethylene glycol, stearic acid, and titanium dioxide.
