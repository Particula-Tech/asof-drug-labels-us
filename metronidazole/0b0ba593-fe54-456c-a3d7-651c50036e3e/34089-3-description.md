# DESCRIPTION

FLAGYL metronidazole extended-release tablets is an oral formulation of the synthetic nitroimidazole antimicrobial agent, 2-methyl-5-nitro-1H-imidazole-1-ethanol, which has the following structural formula:

FLAGYL (metronidazole) extended-release tablets, 750 mg (indicated below as FLAGYL ER) contain 750 mg of metronidazole USP.
Inactive ingredients include hypromellose, lactose, magnesium stearate, polyethylene glycol, poly (meth) acrylic acid ester copolymers, polysorbate 80, silicon dioxide, simethicone emulsion, talc, titanium dioxide, FD&C Blue No. 2 Aluminum Lake.
