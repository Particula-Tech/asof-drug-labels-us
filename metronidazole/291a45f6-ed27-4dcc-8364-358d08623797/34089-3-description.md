# DESCRIPTION

Metronidazole is an oral synthetic antiprotozoal and antibacterial agent, 1 (β-hydroxyethyl)-2-methyl-5-nitroimidazole, which has the following structural formula:

Each tablet for oral administration contains 250 mg or 500 mg of metronidazole.
Inactive ingredients include microcrystalline cellulose, crospovidone, colloidal silicon dioxide and hydrogenated vegetable oil.
