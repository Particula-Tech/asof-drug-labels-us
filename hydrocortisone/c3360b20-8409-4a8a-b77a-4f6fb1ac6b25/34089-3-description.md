# DESCRIPTION

Locoid® (hydrocortisone butyrate) Solution, 0.1% contains the topical corticosteroid, hydrocortisone butyrate, a non-fluorinated hydrocortisone ester.
It has the chemical name: 11β,17,21-Trihydroxypregn-4-ene-3,20-dione 17-butyrate; the molecular formula: C25H36O6; the molecular weight: 432.54; and the CAS registry number: 13609-67-1.

Each mL of Locoid® Solution contains 1 mg of hydrocortisone butyrate in a vehicle consisting of isopropyl alcohol (50% v/v), glycerin, povidone, anhydrous citric acid, sodium citrate and purified water.
