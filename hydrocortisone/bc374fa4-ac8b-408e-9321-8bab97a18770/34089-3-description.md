# DESCRIPTION

Hydrocortisone Cream USP, 1% contains hydrocortisone [pregn-4-ene-3,20-dione, 11,17,21-trihydroxy-, (11ß)-], with the molecular formula C21H30O5 and molecular weight 362.47.
Each gram contains 10 mg of hydrocortisone in a base containing glyceryl monostearate, polyoxyl 40 stearate, glycerin, paraffin, stearyl alcohol, isopropyl palmitate, sorbitan monostearate, benzyl alcohol, potassium sorbate, lactic acid, and purified water.
