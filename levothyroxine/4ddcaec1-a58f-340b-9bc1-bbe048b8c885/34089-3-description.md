# 11 DESCRIPTION

Levothyroxine Sodium Tablets contain the active ingredient, levothyroxine, a synthetic crystalline L-3,3',5,5'- tetraiodothyronine in sodium salt form.
Synthetic T4 is identical in chemical structure to the T4 produced in the human thyroid gland.

Levothyroxine Sodium Tablets for oral administration are available in the following strengths: 25 mcg, 50 mcg, 75 mcg, 88 mcg, 100 mcg, 112 mcg, 125 mcg, 137 mcg, 150 mcg, 175 mcg, 200 mcg, and 300 mcg.
Each levothyroxine sodium tablet contains the inactive ingredients butylatedhydroxy toluene, calcium phosphate dibasic dihydrate, magnesium stearate, microcrystalline cellulose, povidone, sodium starch glycolate, and color additive(s).
