# 11 DESCRIPTION

THYQUIDITY (levothyroxine sodium) oral solution contains synthetic L-3,3',5,5'-tetraiodothyronine sodium salt [levothyroxine (T4) sodium].
Synthetic T4 is chemically identical to that produced in the human thyroid gland, and is very slightly soluble in water.

THYQUIDITY oral solution is supplied in the following strength: 100 mcg per 5 mL (20 mcg per mL).
THYQUIDITY oral solution contains the inactive ingredients citric acid monohydrate, glycerin, methylparaben sodium, sodium hydroxide and purified water.
