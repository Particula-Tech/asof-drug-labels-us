# DESCRIPTION

TIROSINT™ (levothyroxine sodium) capsules are soft gelatin capsules to be orally administered, which contain synthetic L-3,3',5,5'-tetraiodothyronine sodium salt [levothyroxine (T4) sodium].
Synthetic T4 is identical to that produced in the human thyroid gland.
