# 11 DESCRIPTION

ERMEZA (levothyroxine sodium) oral solution contains synthetic L-3,3', 5,5'-tetraiodothyronine sodium salt [levothyroxine (T4) sodium].
Synthetic T4 is chemically identical to that produced in the human thyroid gland, and is very slightly soluble in water.

ERMEZA oral solution is supplied in the following strength: 150 mcg/5 mL (30 mcg/mL).
ERMEZA oral solution contains the following inactive ingredients: edetate disodium, glycerin, and purified water.
