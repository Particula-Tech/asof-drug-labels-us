# DESCRIPTION

Calcijex (calcitriol injection) is synthetically manufactured calcitriol and is available as a sterile, isotonic, clear, colorless to yellow, aqueous solution for intravenous injection.
Calcijex is available in 1 mL ampuls.
Each 1 mL contains calcitriol, 1 mcg; Polysorbate 20, 4 mg; sodium ascorbate 2.5 mg added.
May contain hydrochloric acid and/or sodium hydroxide for pH adjustment. pH is 6.5 (5.9 to 7.0).
Contains no more than 1 mcg/mL of aluminum.

Calcitriol is a crystalline compound which occurs naturally in humans.
It is soluble in organic solvents but relatively insoluble in water.

Calcitriol is chemically designated (5Z,7E)-9, 10-secocholesta-5,7,10(19)-triene-1α,3β,25-triol and has the following structural formula:

Molecular Formula: C27H44O3

The other names frequently used for calcitriol are 1α,25-dihydroxycholecalciferol, 1α,25-dihydroxyvitamin D3, 1,25-DHCC, 1,25(OH)2D3 and 1,25-diOHC.
