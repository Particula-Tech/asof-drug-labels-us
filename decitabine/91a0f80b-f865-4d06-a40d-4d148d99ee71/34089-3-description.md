# 11 DESCRIPTION

Decitabine

Decitabine is a nucleoside metabolic inhibitor.

INQOVI

INQOVI (decitabine and cedazuridine) tablets, for oral use contain 35 mg decitabine and 100 mg cedazuridine.
The tablets are biconvex, oval-shaped, film-coated, red and debossed with “H35” on one side.
Each film-coated tablet contains the following inactive ingredients: lactose monohydrate, hypromellose, croscarmellose sodium, colloidal silicon dioxide, and magnesium stearate.
The film coating material contains polyvinyl alcohol, titanium dioxide, polyethylene glycol, talc, and iron oxide red.
