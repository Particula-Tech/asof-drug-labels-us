# 11 DESCRIPTION

HYFTOR ®(sirolimus topical gel) 0.2% is an mTOR inhibitor immunosuppressant for topical use.
Each gram contains 2 mg of sirolimus, which is solubilized in a gel consisting of alcohol 51%, Carbomer 940, purified water, and trolamine.

Chemically, sirolimus is designated as (3 S,6 R,7 E,9 R,10 R,12 R,14 S,15 E,17 E,19 E,21 S,23 S,26 R,27 R,34a S)-9,10,12,13,14,21,22,23,24,25,26,27,32,33,34,34a-hexadecahydro-9,27-dihydroxy-3-[(1 R)-2-[(1 S,3 R,4 R)-4-hydroxy-3-methoxycyclohexyl]-1-methylethyl]-10,21-dimethoxy-6,8,12,14,20,26-hexamethyl-23,27-epoxy-3 H-pyrido[2,1- c][1,4]oxaazacyclohentriacontine-1,5,11,28,29(4 H,6 H,31 H)-pentone.
