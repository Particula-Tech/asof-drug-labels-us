# 16 HOW SUPPLIED/STORAGE AND HANDLING

AK-FLUOR® (fluorescein injection, USP) 10% is supplied in a single-dose 5 mL glass vial with a gray chlorobutyl serum siliconized stopper and orange flip-off cap.
It contains a sterile dark reddish orange solution of fluorescein sodium.

(NDC 81298-8660-3) 5 mL, single dose vials in a package of 12.

AK-FLUOR® should be stored at 20° to 25°C (68° to 77°F) [See USP Controlled Room Temperature].
Do not freeze.
Discard unused portion.
