# DESCRIPTION

Xyrem (sodium oxybate) is a central nervous system depressant that reduces excessive daytime sleepiness and cataplexy in patients with narcolepsy.
Sodium oxybate is intended for oral administration.
The chemical name for sodium oxybate is sodium 4-hydroxybutyrate.
The molecular formula is C4H7NaO3 and the molecular weight is 126.09 grams/mole.
The chemical structure is:

Sodium oxybate is a white to off-white, crystalline powder that is very soluble in aqueous solutions.
Xyrem oral solution contains 500 mg of sodium oxybate per milliliter of USP Purified Water, neutralized to pH 7.5 with malic acid.
