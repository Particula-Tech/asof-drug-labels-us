# 3 DOSAGE FORMS AND STRENGTHS

CADUET tablets are formulated for oral administration in the following strength combinations:

| 10 | 20 | 40 | 80 |  |  |
| --- | --- | --- | --- | --- | --- |
|  |  | Atorvastatin (mg) |  |  |  |
| Amlodipine (mg) | 2.5 | X | X | X | -- |
| 5 | X | X | X | X |  |
| 10 | X | X | X | X |  |

Combinations of atorvastatin with 2.5 mg and 5 mg amlodipine are film-coated white, and combinations of atorvastatin with 10 mg amlodipine are film-coated blue.
