# 11 DESCRIPTION

Sotalol hydrochloride tablets, USP (AF) contains sotalol hydrochloride USP, an antiarrhythmic drug with Class II (beta-adrenoreceptor blocking) and Class III (cardiac action potential duration prolongation) properties.
Sotalol hydrochloride tablets, USP (AF) are supplied as a light orange, round tablets for oral administration.
Sotalol hydrochloride, USP is a white to off-white powder with a molecular weight of 308.8.
It is freely soluble in water, soluble in alcohol, very slightly soluble in chloroform.
Chemically, sotalol hydrochloride is d,l-N-[4-[1-hydroxy-2-[(1-methylethyl)amino]ethyl]phenyl]methane-sulfonamide monohydrochloride.
