# 11 DESCRIPTION

Sotalol hydrochloride tablets USP contains sotalol hydrochloride, USP an antiarrhythmic drug with Class II (beta-adrenoreceptor blocking) and Class III (cardiac action potential duration prolongation) properties Sotalol hydrochloride tablets USP are supplied as a light blue, oval-shaped tablet for oral administration.
Sotalol hydrochloride, USP is a white, crystalline solid with a molecular weight of 308.8.
It is hydrophilic, soluble in water, propylene glycol and ethanol, but is only slightly soluble in chloroform.
Chemically, sotalol hydrochloride, USP is d,l-N-[4-[1-hydroxy-2-[(1-methylethyl) amino]ethyl]phenyl]methane-sulfonamide monohydrochloride.
