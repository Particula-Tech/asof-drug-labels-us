# 11 DESCRIPTION

Sotalol Hydrochloride Tablets, USP contain sotalol hydrochloride, an antiarrhythmic drug with Class II (beta­ adrenoreceptor blocking) and Class III (cardiac action potential duration prolongation) properties.
Sotalol Hydrochloride Tablets, USP are supplied as a light-blue, capsule-shaped tablet for oral administration.
Sotalol hydrochloride is a white, crystalline solid with a molecular weight of 308.8.
It is hydrophilic, soluble in water, propylene glycol and ethanol, but is only slightly soluble in chloroform.
Chemically, sotalol hydrochloride is d,l-N-[4-[1-hydroxy-2-[(1-methylethyl) amino]ethyl]phenyl]methane-sulfonamide monohydrochloride.
