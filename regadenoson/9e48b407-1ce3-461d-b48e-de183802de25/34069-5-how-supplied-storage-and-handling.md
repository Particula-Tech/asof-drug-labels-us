# 16 HOW SUPPLIED

Regadenoson Injection is supplied as a sterile, clear, colorless preservative-free solution containing 0.08 mg/mL regadenoson in the following package:

- Single-dose 0.4 mg/5 mL pre-filled plastic syringes with luer-lock fitting (NDC 0641-6253-01).

Store at 20° to 25°C (68° to 77°F); excursions permitted to 15° to 30°C (59° to 86°F) [See USP Controlled Room Temperature].
Discard unused portion.
