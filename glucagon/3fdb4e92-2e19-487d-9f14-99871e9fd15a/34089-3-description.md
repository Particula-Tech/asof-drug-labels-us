# 11 DESCRIPTION

BAQSIMI contains glucagon, an antihypoglycemic agent used to treat severe hypoglycemia.
Glucagon is a single-chain polypeptide containing 29 amino acid residues and has a molecular weight of 3483, and is identical to human glucagon.

BAQSIMI is a preservative-free, white powder for intranasal administration in an intranasal device containing one dose of 3 mg glucagon.
BAQSIMI contains glucagon as the active ingredient and betadex, and dodecylphosphocholine as the excipients.
