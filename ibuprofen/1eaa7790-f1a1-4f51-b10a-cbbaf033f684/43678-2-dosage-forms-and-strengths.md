# 3 DOSAGE FORMS AND STRENGTHS

CALDOLOR (ibuprofen injection) is a clear, colorless, non-pyrogenic, aqueous solution intended for intravenous use available in following strengths:

- 800 mg/8 mL (100 mg/mL) single dose vial
- 800 mg/200 mL (4 mg/mL) single dose, ready-to-use, polypropylene, flexible bag
