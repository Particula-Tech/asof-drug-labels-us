# 11 DESCRIPTION

BELRAPZO (bendamustine hydrochloride) is an alkylating agent.
The chemical name of bendamustine hydrochloride is 1H-benzimidazole-2-butanoic acid, 5-[bis(2-chloroethyl)amino]-1-methyl-, monohydrochloride.
Its empirical molecular formula is C16H21Cl2N3O2 HCl, and the molecular weight is 394.7.

BELRAPZO (bendamustine hydrochloride) injection for intravenous use is supplied as a sterile, clear, and colorless to yellow ready-to-dilute solution in a multiple-dose clear glass vial.
