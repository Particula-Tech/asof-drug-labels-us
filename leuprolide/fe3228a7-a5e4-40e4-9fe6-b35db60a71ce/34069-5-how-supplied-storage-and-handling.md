# HOW SUPPLIED

ELIGARD® is available in a single use kit.
The kit consists of a two-syringe mixing system, a sterile needle (Table 9), a silicone desiccant pouch to control moisture uptake, and a package insert for constitution and administration procedures.
Each syringe is individually packaged.
One contains the ATRIGEL® Delivery System and the other contains leuprolide acetate.
When constituted, ELIGARD® is administered as a single dose.

Table 9.
ELIGARD® Needle specifications

| ELIGARD® formulation | Gauge | Length |
| --- | --- | --- |
| 7.5 mg | 20-gauge | ½-inch |
| 22.5 mg | 20-gauge | ½-inch |
| 30 mg | 20-gauge | 5/8-inch |
| 45 mg | 18-gauge | 5/8-inch |

Store at 2 – 8 °C (35.6 – 46.4 °F)
