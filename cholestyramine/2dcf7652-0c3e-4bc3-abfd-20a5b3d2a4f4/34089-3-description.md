# DESCRIPTION

Cholestyramine for oral suspension USP light powder, the chloride salt of a basic anion exchange resin, a cholesterol lowering agent, is intended for oral administration.
Cholestyramine resin is quite hydrophilic, but insoluble in water.
The cholestyramine resin in cholestyramine for oral suspension USP light powder is not absorbed from the digestive tract.
Four grams of anhydrous cholestyramine resin is contained in 5.5 grams of cholestyramine for oral suspension USP light powder.
