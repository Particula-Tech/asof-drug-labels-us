# DESCRIPTION

Prevalite® (cholestyramine for oral suspension, USP) powder, the chloride salt of a basic anion exchange resin, a cholesterol-lowering agent, is intended for oral administration.
Cholestyramine resin is quite hydrophilic, but insoluble in water.
The cholestyramine resin in Prevalite® (cholestyramine for oral suspension, USP) is not absorbed from the digestive tract.
5.5 grams of Prevalite® (cholestyramine for oral suspension, USP) contain 4 grams of anhydrous cholestyramine resin.
