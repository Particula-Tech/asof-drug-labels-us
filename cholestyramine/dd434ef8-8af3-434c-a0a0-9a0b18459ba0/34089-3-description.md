# DESCRIPTION

Prevalite® (Cholestyramine for Oral Suspension, USP), the chloride salt of a basic anion exchange resin, a cholesterol-lowering agent, is intended for oral administration.
Cholestyramine resin is quite hydrophilic, but insoluble in water.
The cholestyramine resin in Prevalite® is not absorbed from the digestive tract.
5.5 grams of Prevalite® contain 4 grams of anhydrous cholestyramine resin.
