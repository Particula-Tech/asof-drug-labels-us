# DESCRIPTION

Cholestyramine for oral suspension, USP, the chloride salt of a basic anion exchange resin, a cholesterol lowering agent, is intended for oral administration.
Cholestyramine resin is quite hydrophilic, but insoluble in water.
Cholestyramine resin is not absorbed from the digestive tract.
