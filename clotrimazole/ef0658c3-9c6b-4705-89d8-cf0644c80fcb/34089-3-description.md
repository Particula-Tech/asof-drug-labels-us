# 11 DESCRIPTION

CLOTIC is a sterile preservative-free otic solution containing clotrimazole, an azole antifungal agent, at a concentration of 1% in polyethylene glycol (PEG) 400.
The solution is clear colorless to slightly yellow.
Each single-dose vial of CLOTIC delivers approximately 0.17 mL of solution equivalent to 1.7 mg of clotrimazole.
