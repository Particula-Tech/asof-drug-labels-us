# DESCRIPTION

Levocarnitine is a carrier molecule in the transport of long-chain fatty acids across the inner mitochondrial membrane.
The chemical name of levocarnitine is (R)-3-carboxy-2-hydroxy-N,N,N-trimethy-1-propanaminium hydroxide, inner salt.
Levocarnitine is a white, crystalline powder or colourless crystals.
It is freely soluble in water, soluble in warm alcohol, practically insoluble in acetone.
The specific rotation of levocarnitine is between -29° and -32°.
Its chemical structure is:

Empirical Formula: C7H15NO3 Molecular Weight: 161.20 Each levocarnitine tablet, USP intended for oral administration contains 330 mg of levocarnitine.
In addition, it also contains the following inactive ingredients: magnesium stearate, microcrystalline cellulose, povidone and sodium starch glycolate.
