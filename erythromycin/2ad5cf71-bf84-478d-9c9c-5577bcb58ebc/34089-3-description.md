# DESCRIPTION

Staticin® (erythromycin topical solution) 1.5% contains erythromycin for topical dermatologic use.
Erythromycin is a macrolide antibiotic produced from a strain of Saccaropolyspora erythraea (formerly Streptomyces erythreus).
It is a base and readily forms salts with acids.

Chemically, erythromycin is C37H67NO13.

Erythromycin has the molecular weight of 733.94.
It is a white to grayish white or pale yellow crystalline powder.

Each mL of Staticin contains 15 milligrams of erythromycin in a base of 55% alcohol, fragrance, laureth-4, and propylene glycol.
