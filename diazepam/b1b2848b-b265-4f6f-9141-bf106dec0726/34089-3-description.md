# DESCRIPTION

Diazepam rectal gel rectal delivery system is a non-sterile diazepam gel provided in a prefilled, unit-dose, rectal delivery system.
Diazepam rectal gel contains 5 mg/mL diazepam, benzoic acid, benzyl alcohol (1.5%), ethyl alcohol (10%), hydroxypropyl methylcellulose, propylene glycol, purified water, and sodium benzoate.
Diazepam rectal gel is clear to slightly yellow and has a pH between 6.5-7.2.

Diazepam, the active ingredient of diazepam rectal gel, is a benzodiazepine anticonvulsant with the chemical name 7-chloro-1,3-dihydro-1-methyl-5-phenyl-2 H-1,4-benzodiazepin-2-one.
