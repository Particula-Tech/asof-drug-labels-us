# DESCRIPTION

Diazepam Injection, USP is a sterile, nonpyrogenic solution intended for intramuscular or intravenous administration.
Each milliliter (mL) contains 5 mg diazepam; 40% propylene glycol; 10% alcohol; 5% sodium benzoate and benzoic acid added as buffers; and 1.5% benzyl alcohol added as a preservative. pH 6.6 (6.2 to 6.9).
Note: Solution may appear colorless to light yellow.

Diazepam is a benzodiazepine derivative chemically designated as 7-chloro-1,3-dihydro-1-methyl-5-phenyl-2H-1,4-benzodiazepin-2-one.
