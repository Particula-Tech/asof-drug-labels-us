# PRINCIPAL DISPLAY PANEL - 2 mg

NDC 0378-0271-05

Diazepam Tablets, USP CIV 2 mg

PHARMACIST: Dispense the Medication Guide provided separately to each patient.

Rx only 500 Tablets

Each tablet contains: Diazepam, USP 2 mg

Usual Dosage: See accompanying prescribing information.

Keep this and all medication out of the reach of children.

Store at 20° to 25°C (68° to 77°F).
[See USP Controlled RoomTemperature.]

Protect from light.

Medication Guides may be obtained at Mylan.com/MedCenter or call 1-888-839-8993.

Dispense in a tight, light-resistant container as defined in the USP using a child-resistant closure.

Keep container tightly closed.

Code No.: MH/DRUGS/AD/089
