# 11 DESCRIPTION

Diazepam, the active ingredient of VALTOCO nasal spray, is a benzodiazepine anticonvulsant with the chemical name 7-chloro-1,3-dihydro-1-methyl-5-phenyl-2H-1,4-benzodiazepin-2-one.
