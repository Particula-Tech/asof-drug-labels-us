# PRINCIPAL DISPLAY PANEL - 5 mg Device Blister Pack Carton

NDC 72252-505-02

Rx Only

VALTOCO® (diazepam nasal spray) CIV

5 mg

FOR NASAL USE ONLY.

5 mg = 1 NASAL SPRAY DEVICE DEVICE SPRAYS ONE TIME ONLY

Do NOT open blister packs or test nasal sprays before use.

This box contains 2 blister packs.
Each blister pack contains 1 nasal spray device.
1 device contains 1 dose (5 mg)

ATTENTION PHARMACIST: The entire carton is to be dispensed as a unit.
Dispense the enclosed medication guide to the patient.

Check product expiration date before use.
