# DESCRIPTION

Fluphenazine hydrochloride is a trifluoromethyl phenothiazine derivative intended for the management of schizophrenia.
Each mL of Fluphenazine Hydrochloride Oral Solution USP (Concentrate), for oral administration, contains fluphenazine hydrochloride, 5 mg; alcohol, 14%.
In addition, each mL contains the following inactive ingredients: glycerin, purified water, and sodium benzoate.
Fluphenazine hydrochloride has the following structure:

4-[3-[2-(Trifluoromethyl)phenothiazin-10-yl]propyl]-1-piperazineethanol dihydrochloride
