# DESCRIPTION

Bromocriptine mesylate is an ergot derivative with potent dopamine receptor agonist activity.
Each bromocriptine mesylate tablet, USP for oral administration contains 2.5 mg bromocriptine (as the mesylate).
Bromocriptine mesylate is chemically designated as Ergotaman-3',6',18-trione, 2-bromo-12'-hydroxy-2'-(1-methylethyl)-5'-(2-methylpropyl)-,(5'α)-monomethanesulfonate (salt).

The structural formula is:

Active Ingredient: bromocriptine mesylate, USP

Inactive Ingredients: anhydrous lactose, colloidal silicon dioxide, magnesium stearate, maleic acid, povidone and pregelatinized starch.

Complies with USP dissolution test 1.
