# DESCRIPTION

Norethindrone acetate tablets USP - 5 mg oral tablets Norethindrone acetate USP, (17-hydroxy-19-nor-17α-pregn-4-en-20-yn-3-one acetate), a synthetic, orally active progestin, is the acetic acid ester of norethindrone.
It is a white, or creamy white, crystalline powder.

Norethindrone acetate tablets USP, 5 mg contain the following inactive ingredients: colloidal silicon dioxide, lactose monohydrate, magnesium stearate, microcrystalline cellulose and talc.
