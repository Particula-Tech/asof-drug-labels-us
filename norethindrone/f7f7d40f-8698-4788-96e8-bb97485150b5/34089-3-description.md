# DESCRIPTION

Aygestin (norethindrone acetate tablets, USP) - 5 mg oral tablets.
Aygestin, (17-hydroxy-19-nor-17α-pregn-4-en-20-yn-3-one acetate), a synthetic, orally active progestin, is the acetic acid ester of norethindrone.
It is a white, or creamy white, crystalline powder.

Aygestin Tablets contain the following inactive ingredients: lactose, magnesium stearate, and microcrystalline cellulose.
