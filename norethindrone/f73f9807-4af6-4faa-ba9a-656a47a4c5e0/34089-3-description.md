# DESCRIPTION

Norethindrone Acetate Tablets USP (17-hydroxy-19-nor-17α-pregn-4-en-20-yn-3-one acetate), a synthetic, orally active progestin, is the acetic acid ester of norethindrone.
It is a white, or creamy white, crystalline powder.
The structural formula is as follows:

C22H28O3 M.W.
340.46

Each Norethindrone Acetate Tablet USP, for oral administration, contains norethindrone acetate, USP 5 mg.
In addition, each tablet contains the following inactive ingredients: anhydrous lactose, magnesium stearate, and microcrystalline cellulose.
