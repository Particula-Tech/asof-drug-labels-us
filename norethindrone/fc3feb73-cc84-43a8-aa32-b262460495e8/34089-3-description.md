# 11 DESCRIPTION

MYFEMBREE tablets for oral administration contain a fixed-dose combination of relugolix 40 mg, estradiol 1 mg, and norethindrone acetate 0.5 mg as active ingredients.

Relugolix is a non-peptide small molecule, GnRH receptor antagonist.
It is a white to off white to slightly yellow solid and is sparingly soluble in water.
