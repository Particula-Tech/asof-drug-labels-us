# 11 DESCRIPTION

AndroGel 1.62% for topical use is a clear, colorless gel containing testosterone.
Testosterone is an androgen.
AndroGel 1.62% is available in a metered-dose pump or unit dose packets.

The active pharmacologic ingredient in AndroGel 1.62% is testosterone.
Testosterone USP is a white to almost white powder chemically described as 17-beta hydroxyandrost-4-en-3-one.
