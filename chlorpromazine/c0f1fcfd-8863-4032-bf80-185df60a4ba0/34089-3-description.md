# DESCRIPTION

Chlorpromazine HCl is chemically designated as 2-Chloro-10-[3-(dimethylamino)propyl]-phenothiazine monohydrochloride and has the following structural formula:

C17H19ClN2S • HCl MW 355.33

Chlorpromazine Hydrochloride Injection, USP is a sterile aqueous solution intended for deep intramuscular use.
Each mL contains chlorpromazine hydrochloride 25 mg, ascorbic acid 2 mg, sodium metabisulfite 1 mg, sodium sulfite 1 mg and sodium chloride 6 mg in Water for Injection. pH is 3.4-5.4.
