# 11 DESCRIPTION

Loteprednol etabonate is a corticosteroid.
Its chemical name is chloromethyl 17α-[(ethoxycarbonyl)oxy]-11β-hydroxy-3-oxoandrosta-1,4-diene-17β-carboxylate.
Its molecular formula is C24H31ClO7 and its chemical structure is:

C24H31ClO7 Mol.
Wt.
467.0

INVELTYS (loteprednol etabonate ophthalmic suspension) 1% contains a sterile, topical anti-inflammatory corticosteroid for ophthalmic use.
Each mL contains:

- ACTIVE: loteprednol etabonate 10 mg (1%)
- INACTIVES: glycerin, sodium citrate dihydrate, Poloxamer 407, sodium chloride, edetate disodium dihydrate, citric acid, and water for injection
- PRESERVATIVE: benzalkonium chloride 0.01%
