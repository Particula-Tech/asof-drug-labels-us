# 11 DESCRIPTION

Loteprednol etabonate is a corticosteroid.
Its chemical name is chloromethyl 17α-[(ethoxycarbonyl)oxy]-11β-hydroxy-3-oxoandrosta-1,4-diene-17β-carboxylate.
Its molecular formula is C24H31ClO7 and its chemical structure is:

C24H31ClO7 Mol.
Wt.
467.0

EYSUVIS (loteprednol etabonate ophthalmic suspension) 0.25% contains a sterile, topical anti-inflammatory corticosteroid for ophthalmic use.
Each mL contains:

- ACTIVE: loteprednol etabonate 2.5 mg (0.25%)
- INACTIVES: glycerin, sodium citrate dihydrate, sodium chloride, Poloxamer 407, edetate disodium dihydrate, citric acid, and water for injection.
- PRESERVATIVE: benzalkonium chloride 0.01%
