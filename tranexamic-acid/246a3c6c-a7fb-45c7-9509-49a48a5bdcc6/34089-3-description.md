# DESCRIPTION

Each mL of the sterile aqueous solution for intravenous injection contains 100 mg tranexamic acid USP.
FORMULATION Chemical Name: trans-4-(aminomethyl)cyclohexanecarboxylic acid Structural Formula: Tranexamic acid USP is a white or almost white, crystalline powder.
The aqueous solution for injection has a pH of 6.5 to 8.0.
