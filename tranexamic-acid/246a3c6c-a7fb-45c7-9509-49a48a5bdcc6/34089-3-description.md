# 11 DESCRIPTION

Tranexamic acid is trans-4-(aminomethyl)cyclohexanecarboxylic acid, an antifibrinolytic agent.
Tranexamic acid USP is a white or almost white, crystalline powder.
The structural formula is Molecular Formula: C8H15NO2 Molecular Weight: 157.2 Each mL of the sterile, clear, colorless solution for intravenous injection contains 100 mg tranexamic acid USP and water for injection to 1 mL.
The aqueous solution for injection has a pH of 6.5 to 8.0.
