# 16 HOW SUPPLIED/STORAGE AND HANDLING

Tranexamic acid USP tablets are provided as white oval-shaped 650 mg tablets.
Each tablet is debossed with the marking “FP650”and are supplied as:

| Quantity | Package Type | NDC Number |
| --- | --- | --- |
| 30 tablets | HDPE bottle | 69918-301-30 |

Storage

Store at room temperature 25° C (77° F); excursions permitted to 15-30° C (59-86° F). [See USP Controlled Room Temperature].
