# 16 HOW SUPPLIED/STORAGE AND HANDLING

## 16.1 How Supplied

Langlara (insulin glargine) injection is supplied as a clear and colorless solution containing 100 units/mL (U-100) available as follows:

| Langlara | NDC number | Package size |  |
| --- | --- | --- | --- |
| 3 mL single-patient-use prefilled pen | 87682-090-05 | 5 pens per carton |  |

Additional Information about Langlara Solostar:

- The Langlara SoloStar prefilled pen dials in 1-unit increments.
- Needles are not included in the packs.

Use BD Ultra-Fine ®needles ‡with the SoloStar prefilled pens (these BD manufactured needles are sold separately).

## 16.2 Storage

Dispense in the original sealed carton with the enclosed Instructions for Use.

Store unused Langlara in a refrigerator between 36°F and 46°F (2°C and 8°C).
Do not freeze.
Discard Langlara if it has been frozen.
Protect Langlara from direct heat and light.
