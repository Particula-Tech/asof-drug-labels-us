# 16 HOW SUPPLIED/STORAGE AND HANDLING

Desloratadine oral solution is a clear, colorless to slightly yellow solution with characteristic bubble gum odor containing 0.5 mg/mL desloratadine and is available in the following size:

4 fl oz (118 mL) NDC 74157-011-01.

Store at 20° to 25° C (68° to 77° F) [see USP Controlled Room Temperature].
Protect from light.
