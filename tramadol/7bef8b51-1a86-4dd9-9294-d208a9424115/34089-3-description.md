# DESCRIPTION

RYBIX™ ODT (tramadol hydrochloride) Orally Disintegrating Tablets is a centrally acting analgesic in an orally disintegrating formulation using a tablet formulation base.
The chemical name for tramadol hydrochloride is (±) cis -2-[(dimethylamino)methyl]-1-(3-methoxyphenyl) cyclohexanol hydrochloride.

RYBIX ODT is supplied as orally disintegrating tablets containing 50 mg of tramadol hydrochloride for oral administration.

Tramadol hydrochloride is a white, bitter, crystalline and odorless powder.
It is readily soluble in water and ethanol and has a pKa of 9.41.
The n-octanol/water log partition coefficient (logP) is 1.35 at pH 7.

The tablets are white in color and contain the inactive ingredients aspartame, copovidone, crospovidone, ethylcellulose, magnesium stearate, mannitol, mint flavor, and silicon dioxide.
