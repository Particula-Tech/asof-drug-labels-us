# 11 DESCRIPTION

Taclonex Topical Suspension contains calcipotriene hydrate and betamethasone dipropionate.
It is for topical use only.
Calcipotriene hydrate is a synthetic vitamin D3 analog.

Taclonex® Topical Suspension

Each gram of Taclonex Topical Suspension contains 50 mcg of calcipotriene (equivalent to 52.2 mcg of calcipotriene hydrate) and 0.643 mg of betamethasone dipropionate (equivalent to 0.5 mg of betamethasone) in a base of hydrogenated castor oil, polyoxypropylene stearyl ether, all-rac-alpha-tocopherol, butylhydroxytoluene, and mineral oil.
Taclonex Topical Suspension is an odorless, clear to slightly off-white suspension.
