# 16 HOW SUPPLIED/STORAGE AND HANDLING

## 16.1 How Supplied

CARDENE I.V.
(nicardipine hydrochloride) injection is clear, pale yellow to yellow color solution supplied as 25 mg/10 mL (2.5 mg/mL) single-dose vial for intravenous infusion after dilution, is available as below:

| Strength | NDC Number | Package Size |
| --- | --- | --- |
| 25 mg/10 mL (2.5 mg/mL) | NDC 43066-029-01 | 10 mL Single-Dose Vial |
| NDC 43066-029-10 | 10 Single-Dose Vials in carton |  |

## 16.2 Storage and Handling

Store at controlled room temperature 20° C to 25° C (68° F to 77° F), refer to USP Controlled Room Temperature.

Protect from light, store vials in carton until ready to use.

Discard unused portion.
