# 11 DESCRIPTION

CUVPOSA is an anticholinergic drug available as an oral solution containing 1 mg glycopyrrolate per 5 mL.
The chemical name for glycopyrrolate is pyrrolidinium, 3-[(cyclopentylhydroxyphenylacetyl)oxy]-1,1-dimethyl-, bromide.
