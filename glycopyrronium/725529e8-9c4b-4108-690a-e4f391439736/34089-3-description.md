# DESCRIPTION

Glycopyrrolate tablets contain the synthetic anticholinergic, glycopyrrolate.
Glycopyrrolate is a quaternary ammonium compound with the following chemical name: 3-[(cyclopentylhydroxyphenylacetyl)oxy]-1, 1-dimethylpyrrolidinium bromide.

Molecular Formula: C19H28BrNO3 Molecular Weight:398.33

Each tablet for oral administration contains 1 mg or 2 mg Glycopyrrolate, USP.

Inactive Ingredients: Dibasic Calcium Phosphate, Lactose Monohydrate, Magnesium Stearate, Povidone, Sodium Starch Glycolate.
