# DESCRIPTION

Trimethoprim is a synthetic antibacterial available in tablet form for oral administration.
Each scored white tablet contains 100 mg trimethoprim.

Trimethoprim is 5-[(3,4,5-trimethoxyphenyl)methyl]-2,4-pyrimidinediamine.
It is a white to light yellow, odorless, bitter compound with a molecular weight of 290.32 and the molecular formula C14H18N4O3.
