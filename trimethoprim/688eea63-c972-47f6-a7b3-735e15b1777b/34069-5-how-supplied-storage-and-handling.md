# HOW SUPPLIED

PRIMSOL (trimethoprim hydrochloride oral solution) is a dye-free, alcohol-free, bubble gum flavored, oral solution containing trimethoprim hydrochloride equivalent to 50 mg of trimethoprim in each 5 mL.

NDC 69654-501-01: 20 mL (3/4 ounce) NDC 69654-501-05: 473 mL (1 Pint)

Store between 15-25°C (59-77°F).
Dispense in tight, light-resistant glass or PET plastic containers as defined in USP.
Protect from light.
