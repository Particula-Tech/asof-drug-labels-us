# 16 HOW SUPPLIED/STORAGE AND HANDLING

VYKOURA (leucovorin calcium) injection is a clear, colorless to yellow color solution supplied in single-dose vial.
Each carton contains one single-dose vial delivering 10 mg/mL leucovorin in the following strengths:

| Strength | NDC Number |
| --- | --- |
| 50 mg/5 mL (10 mg/mL) | 83831-147-05 |
| 350 mg/35 mL (10 mg/mL) | 83831-148-35 |
| 500 mg/50 mL (10 mg/mL) | 83831-149-50 |

This container closure is not made with natural rubber latex.

Storage and Handling

Store in refrigerator at 2°C to 8°C (36°F to 46°F) in original carton to protect from light.
