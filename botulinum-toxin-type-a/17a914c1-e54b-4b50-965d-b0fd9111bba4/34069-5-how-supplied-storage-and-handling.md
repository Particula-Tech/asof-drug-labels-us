# 16 HOW SUPPLIED/STORAGE AND HANDLING

JEUVEAU (prabotulinumtoxinA-xvfs) for injection is a vacuum-dried powder supplied in a single-dose vial in the following size:

100 Units (NDC 72301-595-10)

Storage

Unopened vials of JEUVEAU should be stored in a refrigerator between 2° to 8°C (36° to 46° F) in the original carton to protect from light.
