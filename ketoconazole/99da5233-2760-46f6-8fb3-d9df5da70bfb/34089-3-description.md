# DESCRIPTION

Ketoconazole Shampoo, 2% is a red-orange liquid for topical application, containing the broad spectrum synthetic antifungal agent ketoconazole in a concentration of 2% in an aqueous suspension.
It also contains: coconut fatty acid diethanolamide, disodium laureth sulfosuccinate, FD & C Red No. 40, hydrochloric acid, imidurea, laurdimonium hydroxypropyl hydrolyzed collagen, PEG-120 methyl glucose dioleate, purified water, sodium chloride, sodium hydroxide, and sodium lauryl ether sulfate.
