# HOW SUPPLIED

PROSTIN VR PEDIATRIC Sterile Solution is available in packages of 5—1 mL ampoules (NDC 0009-3169-01) and as a package of 5×1 mL ampoules (NDC 0009-3169-06).
Each mL contains 500 micrograms alprostadil in dehydrated alcohol.

Store PROSTIN VR PEDIATRIC Sterile Solution in a refrigerator at 2° to 8°C (36° to 46°F).
