# HOW SUPPLIED

MUSE is supplied in individual foil pouches containing one (1) single-dose system per pouch.
MUSE is available in unit cartons containing six (6) systems.
MUSE is available in the following 3 dosage strengths:

| Dosage Strength | NDC Numbers |  | Identifying |
| --- | --- | --- | --- |
| Carton | Pouch | Package Color |  |
| 250 mcg | 0037-8120-06 | 0037-8120-01 | Green |
| 500 mcg | 0037-8130-06 | 0037-8130-01 | Blue |
| 1000 mcg | 0037-8140-06 | 0037-8140-01 | Burgundy |

Rx Only.
