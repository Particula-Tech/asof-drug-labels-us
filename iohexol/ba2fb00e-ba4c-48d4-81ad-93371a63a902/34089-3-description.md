# 11 DESCRIPTION

## 11.1 Chemical Characteristics

OMNIPAQUE (iohexol) is a nonionic, radiographic contrast agent for intravenous use.
OMNIPAQUE is provided as a sterile, pyrogen-free, colorless to pale-yellow solution.
The chemical name of iohexol is Bis(2,3-dihydroxypropyl)-5-[N-(2,3-dihydroxypropyl)-acetamido]-2,4,6- triiodoisophthalamide with a molecular weight of 821.14 (iodine content 46.36%).
Iohexol has the following structural formula:

- OMNIPAQUE 300 mg iodine/mL (647 mg of iohexol/mL): Each mL contains 300 mg organically bound iodine, 1.21 mg tromethamine, 0.1 mg edetate calcium disodium
- OMNIPAQUE 350 mg iodine/mL (755 mg of iohexol/mL): Each mL contains 350 mg organically bound iodine, 1.21 mg tromethamine, 0.1 mg edetate calcium disodium

The pH is adjusted between 6.8 and 7.7 with hydrochloric acid or sodium hydroxide.
All solutions are sterile and contain no preservatives.
