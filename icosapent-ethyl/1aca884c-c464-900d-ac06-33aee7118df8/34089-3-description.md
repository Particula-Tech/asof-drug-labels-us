# 11 DESCRIPTION

Icosapent ethyl capsules, a lipid-regulating agent, is supplied as a 1 gram transparent natural colored oblong shaped, liquid-filled soft gelatin capsule for oral use.

Each icosapent ethyl capsule contains 1 gram of icosapent ethyl (in a 1 gram capsule).
Icosapent ethyl is an ethyl ester of the omega-3 fatty acid eicosapentaenoic acid (EPA).
The empirical formula of icosapent ethyl is C22H34O2 and the molecular weight is 330.51.
