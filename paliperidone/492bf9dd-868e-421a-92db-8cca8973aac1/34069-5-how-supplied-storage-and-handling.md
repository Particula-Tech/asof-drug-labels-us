# 16 HOW SUPPLIED/STORAGE AND HANDLING

How Supplied

ERZOFRI ®is provided as a single-use kit containing a single-dose prefilled syringe with a plunger stopper and tip cap.
The kit also contains 2 safety needles (a 1 ½-inch 22 gauge safety needle and a 1-inch 23 gauge safety needle).

ERZOFRI is available as a white to off-white aqueous suspension in the following strengths:

| 39 mg/0.25 mL paliperidone palmitate kit | (NDC 72526-105-11) |
| --- | --- |
| 78 mg/0.5 mL paliperidone palmitate kit | (NDC 72526-106-11) |
| 117 mg/0.75 mL paliperidone palmitate kit | (NDC 72526-107-11) |
| 156 mg/mL paliperidone palmitate kit | (NDC 72526-108-11) |
| 234 mg/1.5 mL paliperidone palmitate kit | (NDC 72526-109-11) |
| 351 mg/2.25 mL paliperidone palmitate kit | (NDC 72526-110-11) |

Storage and Handling

Store at 20°C to 25°C (68°F to 77°F); excursions permitted between 15°C and 30°C (59°F to 86°F) [see USP Controlled Room Temperature].
Do not mix with any other product or diluent.
