# PRINCIPAL DISPLAY PANEL - 273 mg Syringe Kit

3 MONTHS

Administer every 3 months

Shake syringe vigorously for at least 15 seconds

273 mg/0.88 mL

Each single-dose prefilled syringe contains 273 mg (0.88 mL) paliperidone palmate.

NDC 50458-606-01 Single-dose prefilled syringe.
Use entire contents of syringe.

INVEGA TRINZA® (paliperidone palmitate) extended-release injectable suspension

273 mg/0.88 mL

FOR INTRAMUSCULAR INJECTION ONLY Each injection must be administered only by a healthcare professional.
Shake before using.

CONTENTS: 1 single-dose prefilled syringe and 2 needles (a 22G, 1-inch thin wall safety needle and a 22G, 1½-inch thin wall safety needle)

For recommended dosing instructions, please see accompanying full Package Insert.

Rx only

Store at room temperature 20°C to 25°C (68°F to 77°F); excursions between 15°C and 30°C (59°F and 86°F) are permitted.
