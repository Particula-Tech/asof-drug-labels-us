# 11 DESCRIPTION

Each capsule for oral administration contains lithium carbonate USP, 150 mg, 300 mg or 600 mg and the following inactive ingredients: gelatin, sodium lauryl sulfate, talc, titanium dioxide and the imprinting ink contains black iron oxide E172 dye, butyl alcohol, dehydrated alcohol, isopropyl alcohol, potassium hydroxide, propylene glycol, shellac and strong ammonia solution.

Lithium is an element of the alkali-metal group with atomic number 3, atomic weight 6.94, and an emission line at 671 nm on the flame photometer.

Lithium Carbonate USP is a white, light, alkaline powder with molecular formula Li 2CO 3 and molecular weight 73.89.
