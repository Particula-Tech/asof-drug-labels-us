# 11 DESCRIPTION

Lithium is an element of the alkali-metal group with atomic weight of 6.94.
Lithium Carbonate is a white, light, alkaline powder with molecular formula Li2CO3 and molecular weight 73.89 Each capsule contains 150 mg, 300 mg, or 600 mg lithium carbonate, USP and the following inactive ingredients: gelatin, sodium lauryl sulfate, talc, titanium dioxide and the imprinting ink contains black iron oxide E172 dye, butyl alcohol, dehydrated alcohol, isopropyl alcohol, potassium hydroxide, propylene glycol, shellac and strong ammonia solution.
