# 11 DESCRIPTION

Lithium is an element of the alkali-metal group with atomic weight 6.94.
Lithium Carbonate is a white, light, alkaline powder with molecular formula Li2CO3 and molecular weight 73.89.
Each tablet contains 300 mg of lithium carbonate, USP and the following inactive ingredients: microcrystalline cellulose, povidone, sodium lauryl sulfate, sodium starch glycolate type A, colloidal silicon dioxide and calcium stearate.
