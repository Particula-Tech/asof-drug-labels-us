# 11 DESCRIPTION

Each tablet for oral administration contains lithium carbonate USP, 300 mg and the following inactive ingredients: microcrystalline cellulose, povidone, sodium lauryl sulfate, sodium starch glycolate type A, colloidal silicon dioxide and calcium stearate.

Lithium is an element of the alkali-metal group with atomic number 3, atomic weight 6.94, and an emission line at 671 nm on the flame photometer.

The molecular formula for Lithium Citrate is C6H5Li3O7; molecular weight 209.93.
Lithium acts as an antimanic.

Lithium carbonate USP is a white, light, alkaline powder with molecular formula Li2CO3 and molecular weight 73.89.
