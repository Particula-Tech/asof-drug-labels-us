# DESCRIPTION

Fluocinolone Acetonide Ointment contains Fluocinolone Acetonide USP (Pregna-1,4-diene-3,20-dione, 6,9-difluoro-11,21-dihydroxy-16,17-[(1-methylethylidene)bis(oxy)]-, (6α,11β,16α)-.
It has an empirical formula of C24H30F2O6 and a molecular weight of 452.49 (CAS Registry Number 67-73-2).

Each gram of the ointment contains 0.25 mg Fluocinolone Acetonide in a base containing White Petrolatum.
