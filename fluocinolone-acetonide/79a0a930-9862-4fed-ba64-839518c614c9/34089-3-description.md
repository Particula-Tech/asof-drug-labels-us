# DESCRIPTION

SYNALAR® (fluocinolone acetonide) Cream 0.025% is intended for topical administration.
The active component is the corticosteroid fluocinolone acetonide, which has the chemical name pregna-1,4-diene-3,20-dione,6,9-difluoro-11,21-dihydroxy-16,17-[(1-methylethylidene)bis (oxy)]-,(6α,11β,16α)-.
