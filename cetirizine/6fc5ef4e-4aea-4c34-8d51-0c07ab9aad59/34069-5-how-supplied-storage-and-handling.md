# 16 HOW SUPPLIED/STORAGE AND HANDLING

ZERVIATE ® is a sterile, buffered, clear, colorless aqueous solution containing cetirizine 0.24% (equivalent to cetirizine hydrochloride 0.29%) supplied in 5 low-density polyethylene 0.2 mL single-use containers within a foil pouch.

Carton of 30 single-use containers NDC 82667-015-24

Storage:Store at 15°C to 25°C (59°F to 77°F).

Single-use containers should be stored in the original foil pouch.
