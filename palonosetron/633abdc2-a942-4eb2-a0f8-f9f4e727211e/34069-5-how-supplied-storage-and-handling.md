# 16 HOW SUPPLIED/STORAGE AND HANDLING

NDC # 67184-0514-1, Palonosetron Hydrochloride Injection 0.25 mg/5 mL (free base) single-dose vial individually packaged in a carton.

NDC # 67184-0515-2, Palonosetron Hydrochloride Injection 0.075 mg/1.5 mL (free base) single-dose vial packaged in a carton containing 5 vials.

Storage

- Discard Unused Portion
- Store at 20° to 25°C (68° to 77°F); excursions permitted between 15° to 30°C (59° to 86°F) [See USP Controlled Room Temperature]
- Protect from freezing.
- Protect from light.
