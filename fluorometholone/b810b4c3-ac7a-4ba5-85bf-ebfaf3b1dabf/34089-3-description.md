# DESCRIPTION

FML FORTE® (fluorometholone ophthalmic suspension, USP) 0.25% is a sterile, topical anti-inflammatory agent for ophthalmic use.

Chemical Name

Fluorometholone: 9-Fluoro-11ß, 17-dihydroxy-6α-methylpregna-1,4-diene-3,20-dione

Structural Formula

Contains

Active: fluorometholone 0.25%.
Preservative: benzalkonium chloride 0.005%.
Inactives: edetate disodium; polysorbate 80; polyvinyl alcohol 1.4%; purified water; sodium chloride; sodium phosphate, dibasic; sodium phosphate, monobasic; and sodium hydroxide to adjust pH.
FML FORTE® suspension is formulated with a pH from 6.2 to 7.5.
