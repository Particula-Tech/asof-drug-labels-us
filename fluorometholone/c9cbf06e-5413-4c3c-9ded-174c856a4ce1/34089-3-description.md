# DESCRIPTION

Fluorometholone ophthalmic suspension, USP, 0.1% is a sterile, topical anti-inflammatory agent for ophthalmic use.

Chemical Name

Fluorometholone: 9-Fluoro-11β,17-dihydroxy-6α-methylpregna-1,4-diene-3,20-dione.

Structural Formula

Contains

Active: Fluorometholone 0.1%.
Preservative: Benzalkonium chloride 0.004%.
Inactives: Edetate disodium dihydrate, polysorbate 80, polyvinyl alcohol 1.4%, sodium chloride, sodium hydroxide to adjust pH (6.2 to 7.5), sodium phosphate dibasic (anhydrous), sodium phosphate monobasic (monohydrate), and water for injection.
It has an osmolality range of 290 to 350 mOsm/kg.
