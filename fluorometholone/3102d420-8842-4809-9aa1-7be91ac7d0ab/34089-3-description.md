# DESCRIPTION

FML® (fluorometholone ophthalmic ointment) 0.1 % is a topical anti-inflammatory agent for ophthalmic use.

## Chemical Name:

Fluorometholone: 9-Fluoro-11β, 17-dihydroxy-6α-methylpregna-1,4-diene-3,20-dione

Structural Formula:

Contains: Active: fluorometholone 0.1%.
Preservative: phenylmercuric acetate (0.0008%).Inactives: mineral oil; petrolatum (and) lanolin alcohol; and white petrolatum.
