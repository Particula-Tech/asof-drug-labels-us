# DESCRIPTION

FML® (fluorometholone ophthalmic suspension, USP) 0.1% is a sterile, topical anti-inflammatory agent for ophthalmic use.

Chemical Name

Fluorometholone: 9-Fluoro-11β,17-dihydroxy-6α-methylpregna-1,4-diene-3,20-dione.

Structural Formula

Contains

Active: fluorometholone 0.1%.
Preservative: benzalkonium chloride 0.004%.
Inactives: edetate disodium; polysorbate 80; polyvinyl alcohol 1.4%; purified water; sodium chloride; sodium phosphate, dibasic; sodium phosphate, monobasic; and sodium hydroxide to adjust pH.
FML® suspension is formulated with a pH from 6.2 to 7.5.
It has an osmolality range of 290-350 mOsm/kg.
