# 11 DESCRIPTION

Paricalcitol, USP, is a synthetically manufactured active vitamin D analog.
It is a white powder chemically designated as 19-nor-1α,3β,25-trihydroxy-9,10-secoergosta-5(Z),7(E),22(E)-triene and has the following structural formula:

Molecular formula is C27H44O3.

Molecular weight is 416.64.

ZEMPLAR (paricalcitol) injection is a sterile, clear, colorless, aqueous solution for intravenous use.
Each mL contains paricalcitol, 2 mcg or 5 mcg and the following inactive ingredients: alcohol, 20% (v/v) and propylene glycol, 30% (v/v).
