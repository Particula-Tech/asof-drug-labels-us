# 11 DESCRIPTION

Paricalcitol, USP is a synthetically manufactured active vitamin D analog.
It is a white to almost white powder chemically designated as (1α,3β,7E,22E)-19-Nor-9,10-secoergosta-5,7,22-triene-1,3,25-triol and has the following structural formula:

Molecular formula is C27H44O3.

Molecular weight is 416.64 g/mol.

Paricalcitol injection, USP is a sterile, aqueous solution for intravenous use.
Each mL contains paricalcitol USP, 2 mcg or 5 mcg and the following inactive ingredients: alcohol, 20% (v/v) and propylene glycol, 30% (v/v).
