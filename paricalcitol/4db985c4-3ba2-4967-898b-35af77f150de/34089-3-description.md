# 11 DESCRIPTION

Paricalcitol, USP, the active ingredient in Paricalcitol Injection, is a synthetically manufactured active vitamin D2 analog.

Paricalcitol Injection is available as a sterile, clear, colorless, aqueous solution for intravenous injection.
