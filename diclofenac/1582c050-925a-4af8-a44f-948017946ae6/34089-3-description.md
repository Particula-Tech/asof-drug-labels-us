# DESCRIPTION

Cataflam® (diclofenac potassium immediate-release tablets) is a benzeneacetic acid derivative.
Cataflam is available as immediate-release tablets of 50 mg (light brown) for oral administration.
The chemical name is 2-[(2,6-dichlorophenyl)amino] benzeneacetic acid, monopotassium salt.
The molecular weight is 334.25.
