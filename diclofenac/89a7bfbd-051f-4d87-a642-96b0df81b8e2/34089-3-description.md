# DESCRIPTION

Solaraze® (diclofenac sodium) Gel, 3%, contains the active ingredient, diclofenac sodium, in a clear, transparent, colorless to slightly yellow gel base.
Diclofenac sodium is a white to slightly yellow crystalline powder.
It is freely soluble in methanol, soluble in ethanol, sparingly soluble in water, slightly soluble in acetone, and partially insoluble in ether.
The chemical name for diclofenac sodium is:

Sodium [o-(2,6-dichloranilino) phenyl] acetate

Diclofenac sodium has a molecular weight of 318.13.

The CAS number is CAS-15307-79-6.
