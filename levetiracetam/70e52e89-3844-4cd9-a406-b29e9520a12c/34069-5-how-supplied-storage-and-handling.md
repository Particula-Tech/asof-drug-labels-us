# 16 HOW SUPPLIED/STORAGE AND HANDLING

How Supplied

Levetiracetam in Sodium Chloride Injection is a clear, colorless, sterile solution that is available in a single-use 100 mL dual port bag with an aluminum over wrap.
The container closure is not made with natural rubber latex.
It is available in the following presentations:
