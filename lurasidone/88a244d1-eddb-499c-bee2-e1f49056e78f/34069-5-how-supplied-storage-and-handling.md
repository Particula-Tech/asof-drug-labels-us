# 16. HOW SUPPLIED/STORAGE AND HANDLING

LATUDA tablets are white to off-white, round (40 mg), or pale green, oval (80 mg) and identified with strength specific one-sided debossing, “L40” (40 mg), or “L80” (80 mg).
Tablets are supplied in the following strengths and package configurations (Table 11):

Table 11: Package Configuration for LATUDA Tablets

| Tablet Strength | Package Configuration | NDC Code |
| --- | --- | --- |
| 40 mg | Drum of 1,517,754 | 51148-001-01 |
| 80 mg | Drum of 754,561 | 51148-002-01 |

Storage

Store LATUDA tablets at 25°C (77°F); excursions permitted to 15° - 30°C (59° - 86°F) [See USP Controlled Room Temperature].
