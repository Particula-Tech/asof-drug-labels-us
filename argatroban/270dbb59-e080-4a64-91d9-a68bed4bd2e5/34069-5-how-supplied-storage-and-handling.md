# 16 HOW SUPPLIED/STORAGE AND HANDLING

Argatroban Injection, USP is available in packages as follows: NDC Strength Packaged 68083-568-01 50 mg/50 mL (1 mg/mL) Single Dose Vial Storage and Handling Store the vials in original carton at 20° to 25° C (68° to 77° F) [See USP Controlled Room Temperature].
Do not freeze.
Retain in the original carton to protect from light.
If the solution is cloudy, or if an insoluble precipitate is noted, the vial should be discarded.
