# DESCRIPTION

SILVADENE Cream 1% is a soft, white, water-miscible cream containing the antimicrobial agent silver sulfadiazine in micronized form, which has the following structural formula:

Each gram of SILVADENE Cream 1% contains 10 mg of micronized silver sulfadiazine.
The cream vehicle consists of white petrolatum, stearyl alcohol, isopropyl myristate, sorbitan monooleate, polyoxyl 40 stearate, propylene glycol, and water, with methylparaben 0.3% as a preservative.
SILVADENE Cream 1% (silver sulfadiazine) spreads easily and can be washed off readily with water.
