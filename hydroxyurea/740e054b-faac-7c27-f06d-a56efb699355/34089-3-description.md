# DESCRIPTION

DROXIA® (hydroxyurea capsules, USP) is available for oral use as capsules providing 200 mg, 300 mg, and 400 mg hydroxyurea.
Inactive ingredients: citric acid, gelatin, lactose, magnesium stearate, sodium phosphate, titanium dioxide, and capsule colorants; FD&C Blue #1 and FD&C Green #3 (200 mg capsules); D&C Red #28, D&C Red #33, and FD&C Blue #1 (300 mg capsules); D&C Red #28, D&C Red #33, and D&C Yellow #10 (400 mg capsules).

Hydroxyurea is an essentially tasteless, white crystalline powder.
