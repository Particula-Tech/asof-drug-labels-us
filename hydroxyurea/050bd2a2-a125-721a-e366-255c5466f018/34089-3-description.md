# 11 DESCRIPTION

HYDREA (hydroxyurea capsules, USP) is an antimetabolite available for oral use as capsules containing 500 mg hydroxyurea.
Inactive ingredients include citric acid, colorants (D&C Yellow No. 10, FD&C Blue No. 1, FD&C Red No. 40, and D&C Red No. 28), gelatin, lactose, magnesium stearate, sodium phosphate, and titanium dioxide.

Hydroxyurea is a white crystalline powder.
It has a molecular weight of 76.05.
