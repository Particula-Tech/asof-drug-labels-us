# DESCRIPTION

Cordarone (amiodarone HCl) is a member of a new class of antiarrhythmic drugs with predominantly Class III (Vaughan Williams' classification) effects, available for oral administration as pink, scored tablets containing 200 mg of amiodarone hydrochloride.
The inactive ingredients present are colloidal silicon dioxide, lactose, magnesium stearate, povidone, starch, and FD&C Red 40.
Cordarone is a benzofuran derivative: 2-butyl-3-benzofuranyl 4-[2-(diethylamino)-ethoxy]-3,5-diiodophenyl ketone hydrochloride.
It is not chemically related to any other available antiarrhythmic drug.
