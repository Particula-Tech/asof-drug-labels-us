# 11 DESCRIPTION

Pacerone (amiodarone hydrochloride) tablets are an antiarrhythmic drug, available for oral administration as 100 mg, peach tablets and 200 mg, pink tablets containing amiodarone hydrochloride.
Both strengths of Pacerone tablets contain the following inactive ingredients: lactose monohydrate, magnesium stearate, povidone, pregelatinized corn starch, sodium starch glycolate, stearic acid, FD&C Red 40 (200 mg only) and FD&C Yellow 6.
Amiodarone hydrochloride is a benzofuran derivative: 2-butyl-3-benzofuranyl 4-[2-(diethylamino)-ethoxy]-3,5-diiodophenyl ketone hydrochloride.
