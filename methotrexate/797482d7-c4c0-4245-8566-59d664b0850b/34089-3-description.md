# 11 DESCRIPTION

RediTrex contains methotrexate, a folate analog metabolic inhibitor.

Chemically, methotrexate is [N-[4-[[(2,4-diamino-6-pteridinyl)methyl]methylamino]benzoyl]-Lglutamic acid.
The structural formula is:

C20H22N8O5 M.W. = 454.45

RediTrex contains methotrexate in a sterile, preservative-free, solution in a pre-filled syringe (in a needle safety device) with a 29 gauge ½ inch needle for a single subcutaneous injection.
RediTrex solution is yellow in color.

Inactive ingredients include sodium chloride, sodium hydroxide and water for injection, USP.
Sodium chloride is added to adjust tonicity.
Sodium hydroxide is added to adjust pH to a target pH of 8.2.
