# 11 DESCRIPTION

XATMEP contains methotrexate, a folate analog metabolic inhibitor.

Chemically methotrexate is N-[4-[[(2,4-diamino-6-pteridinyl)methyl]methylamino]-benzoyl]-L-glutamic acid.

XATMEP is a clear yellow to orange oral solution that contains 2.5 mg of methotrexate per milliliter (equivalent to 2.74 mg of methotrexate sodium/mL).
Inactive ingredients include purified water, sodium citrate, citric acid, methylparaben sodium, propylparaben sodium, and sucralose.
It may also contain sodium hydroxide or hydrochloric acid for pH adjustment.
