# DESCRIPTION

Dovonex® (calcipotriene ointment), 0.005% contains the compound calcipotriene, a synthetic vitamin D3 derivative, for topical dermatological use.

Calcipotriene is a white or off-white crystalline substance.
Dovonex® ointment contains calcipotriene 50 μg/g in an ointment base of dibasic sodium phosphate, edetate disodium, mineral oil, petrolatum, propylene glycol, tocopherol, steareth-2 and water.
