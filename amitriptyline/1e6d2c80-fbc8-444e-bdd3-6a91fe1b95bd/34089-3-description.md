# DESCRIPTION

Amitriptyline HCl, a dibenzocycloheptadiene derivative, is a white, or practically white, odorless, crystalline compound which is freely soluble in water and alcohol.

It is designated chemically as 10,11-Dihydro-N,N-dimethyl-5H-dibenzo[a,d] cycloheptene-Δ5, γ-propylamine hydrochloride.

Each tablet for oral administration contains 10, 25, 50, 75, 100, or 150 mg amitriptyline hydrochloride.
Inactive ingredients include colloidal anhydrous silica, croscarmellose sodium, lactose (monohydrate), lecithin, magnesium stearate, microcrystalline cellulose, polyvinyl alcohol, iron oxide red, talc, titanium dioxide and xanthan gum.
