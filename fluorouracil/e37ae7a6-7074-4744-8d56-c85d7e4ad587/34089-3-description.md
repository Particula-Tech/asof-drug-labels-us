# 11 DESCRIPTION

Tolak (fluorouracil) Cream, 4% contains 40 mg of fluorouracil per gram of white cream for topical application.
It is a nucleoside metabolic inhibitor.
Chemically, fluorouracil is 5-fluoro-2,4 (1H,3H)-pyrimidinedione.
