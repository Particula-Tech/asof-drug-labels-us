# DESCRIPTION

Allopurinol has the following structural formula:

Allopurinol is known chemically as 1,5-Dihydro-4H-pyrazolo[3,4-d]pyrimidin-4-one.
It is a xanthine oxidase inhibitor which is administered orally.
Each scored white tablet contains 100 mg or 300 mg allopurinol, USP and the inactive ingredients colloidal silicon dioxide, magnesium stearate, microcrystalline cellulose, pregelatinized starch (corn), sodium lauryl sulfate and sodium starch glycolate (potato).
Its solubility in water at 37ºC is 80.0 mg/dL and is greater in an alkaline solution.
