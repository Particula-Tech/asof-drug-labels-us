# 16 HOW SUPPLIED/STORAGE AND HANDLING

How Supplied Allopurinol is available in multiple tablet strengths with functional scoring and package sizes (bottles with child-resistant caps) as listed in Table 4.

TABLE 4: Allopurinol Tablets Presentations

| Tablet Strength | Tablet Description | Package Sizes (NDC) |
| --- | --- | --- |

Storage and Handling Store at 20°C to 25°C (USP Controlled Room Temperature) (68°F to 77°F) in a dry place.
Dispense in a tight container as defined in the USP.
